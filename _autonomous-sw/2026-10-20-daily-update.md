  - title: "평균 점수를 올리는 대신 '최악의 순간'만 겨냥하다 — DriveSafer가 재난적 실패를 48% 줄인 방법"
    type: "논문"
    summary: "생성형 End-to-End 플래너는 평균 주행 품질 지표(PDMS 등)는 높아도, 물리적 제약이나 안전 요건을 어기는 '재난적 실패(catastrophic failure)'가 드물지 않게 남아 있다는 게 CMU 연구팀의 출발점이다. DriveSafer는 평균 성능을 더 끌어올리는 대신 실패 자체를 줄이는 데 집중한다는 점이 특징인데, 학습 단계에서는 안전 제약을 어기는 궤적에 추가 페널티를 주는 안전 인지 손실(safety-aware loss)을 쓰고, 추론 단계에서는 생성된 궤적 후보들을 안전 기준으로 다시 거르는 안전 유도 추론(safety-guided inference)을 결합한다. NAVSIM 벤치마크에서 PDMS=0으로 떨어지는 재난적 실패를 48% 줄이면서 PDMS 90.3을 기록했다고 보고하는데, '평균을 높이는 학습'과 '최악을 줄이는 학습'을 분리해서 다룬다는 설계 철학 자체가, End-to-End 모델이 안전성 입증(assurance case)을 어떻게 설득력 있게 만들 수 있는지에 대한 한 가지 구체적인 답을 제시한다는 점에서 눈여겨볼 만하다."
    source_url: "https://arxiv.org/abs/2605.16737"
  - title: "희귀한 사고 장면을 사람이 더 몰지 않고도 늘린다 — SimScale이 '실제 로그 위의 시뮬레이션'으로 증명한 스케일링"
    type: "논문"
    summary: "안전에 중요한 장면이나 분포 밖(out-of-distribution) 상황은 사람이 직접 운전하며 모은 데이터셋에는 원래부터 희귀하다는 문제는 자율주행 학습 데이터의 오래된 딜레마다. OpenDriveLab·Xiaomi EV 연구팀의 SimScale(CVPR 2026)은 새로운 주행 장면을 처음부터 만드는 대신, 기존 주행 로그 위에 신경망 렌더링으로 멀티뷰 카메라 영상을 합성하고, 에고 차량의 궤적을 일부러 흔들어(perturbed trajectory) 반응형 환경 안에서 그 결과를 관찰하는 방식을 쓴다. 여기에 가짜 전문가 궤적 생성기가 행동 레이블까지 붙여주기 때문에, 실제 데이터를 추가로 모으지 않고도 학습 샘플을 늘릴 수 있다. 실제 로그와 시뮬레이션 데이터를 함께 학습시켰을 때 navhard에서 최대 +6.8 EPDMS, navtest에서 +2.9 EPDMS 개선을 보였고, 더 중요한 건 시뮬레이션 데이터를 늘릴수록 성능이 계속 좋아진다는 스케일링 곡선을 실제로 보여줬다는 점이다. '실제 데이터 수집은 선형적으로 느리게 늘지만 시뮬레이션은 그렇지 않다'는 자율주행 학습 데이터 전략의 핵심 전제를 실증적으로 뒷받침하는 사례다."
    source_url: "https://arxiv.org/abs/2511.23369"
