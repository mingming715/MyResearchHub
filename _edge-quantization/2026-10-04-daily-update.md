    type: "논문"
    summary: "PTQ에서 라운드-투-니어러스트 양자화의 채널별 weight scale을 기존처럼 absmax로 어림짐작하는 대신, 캘리브레이션 데이터로 닫힌 형태(closed-form) 최적해를 정확히 계산하는 PiSO(Piecewise Scale Optimization)를 제안한다. 스케일 탐색 공간을 유한한 구간으로 쪼개 각 구간에서 최적해를 구하는 방식으로, 2비트 양자화에서 absmax 대비 perplexity를 자릿수 단위로 줄이고 3~4비트에서도 전 구간 최고 성능을 기록했다. GPTQ·Qronos 같은 기존 오차 보정 기법과 결합해도 추가 개선이 있고, 비트폭이 낮아질수록 이득이 커진다는 점이 핵심인데, 이는 양자화 난이도가 올라갈수록 '스케일을 얼마나 정확히 잡느냐'가 성능을 좌우한다는 것을 보여준다. Llama-3, Qwen-2.5 등 여러 크기 모델에서 검증했고, 단 2048토큰짜리 캘리브레이션 시퀀스 하나만으로도 거의 점근적 품질에 도달해 데이터 효율성까지 챙겼다."
    source_url: "https://arxiv.org/abs/2606.10890"
  - title: "오디오는 이미지와 다르게 양자화된다 — 진화 전략으로 음성 모델 INT4를 '무손실'에 가깝게"
    type: "논문"
    summary: "음성 모델의 activation은 이미지보다 캘리브레이션 범위가 훨씬 넓어, 표준 MSE 기반 캘리브레이션을 그대로 적용하면 정보 손실이 크다는 점을 지적한 논문이다. ESC(Evolution Strategy-based Calibration)는 먼저 FP32-양자화 출력 간 재구성 오차를 최소화하는 MSE 기반 초기 스케일을 잡은 뒤, 미분 불가능한 태스크 손실을 진화 전략으로 직접 최적화하는 local-global 2단계 방식을 제안한다. Whisper 계열을 포함한 여러 음성 태스크에서 INT8은 사실상 무손실, INT4도 거의 무손실 수준의 양자화를 달성했다고 보고한다. 비-이미지 도메인에서는 이미지용 표준 PTQ 캘리브레이션 레시피를 그대로 가져다 쓰면 안 된다는 것을 실증적으로 보여주는 사례로, 도메인별 활성화 분포 특성을 먼저 이해해야 하는 이유를 잘 설명해준다."
    source_url: "https://arxiv.org/abs/2603.08173"
  - title: "Pruning→Quantization→Distillation, 순서를 바꾸면 똑같은 기법도 다른 결과가 나온다"
    type: "논문"
    summary: "모델 경량화에서 가지치기·양자화·지식증류를 각각 따로 비교하는 대신, 세 기법을 '어떤 순서로' 묶어야 하는지를 체계적으로 실험한 논문이다. Global unstructured pruning → INT8 QAT → KD 순서로 구성한 파이프라인에서, pruning은 그 자체의 속도 향상보다는 이후 저정밀도 최적화를 안정시키는 '용량 축소 전처리' 역할을 하고, 실제 런타임 이득의 대부분은 INT8 QAT에서 나오며, KD는 맨 마지막에 붙어 그 제약된 sparse-INT8 환경 안에서 정확도를 회복시키는 역할을 한다는 것을 보였다. 세 단계 순서를 바꿔보는 ablation에서는 정확도 차이가 뚜렷하게 갈리는 반면 레이턴시는 큰 차이가 없었는데, 이는 파라미터·FLOP 같은 proxy 지표만으로는 실제 CPU wall-clock 성능을 예측할 수 없다는 경고이기도 하다. 경량화 기법을 쌓을 때 '무엇을 쓰느냐'보다 '어떤 순서로 쌓느냐'가 결과를 좌우한다는 것을 ResNet-18/WRN-28-10/VGG-16 실험으로 구체화한다."
    source_url: "https://arxiv.org/abs/2604.04988"
  - title: "레이어마다 다른 비트폭, 사람이 아니라 강화학습이 정하게 하라 — RAMP의 제로샷 전이"
    type: "논문"
    summary: "기존 PTQ 대부분이 전 레이어에 균일한 비트폭을 강제해 정확도-효율 트레이드오프가 최적이 아니라는 문제에서 출발해, 레이어별 비트폭 할당을 강화학습(off-policy Soft Actor-Critic)으로 학습하는 RAMP를 제안한다. 활성화 통계·가중치 속성·구조적 특징을 담은 11차원 상태를 입력으로 전역 비트 예산 안에서 perplexity를 최소화하도록 학습하며, 4비트 미만 극저비트 구간의 안정성을 위해 활성화 아웃라이어를 가중치 쪽으로 재분배하는 Scale Folding 전처리도 함께 쓴다. Llama-2-7B에서 학습한 단일 정책이 Llama-2-13B, Mistral-7B에도 제로샷으로 전이되며 종종 해당 모델 전용으로 학습한 정책보다 더 나은 성능을 보였고, 학습된 비트 할당을 GGUF로 바로 내보내 커널 수정 없이 CPU·GPU·엣지에 배포할 수 있다는 점도 실용적이다. '양자화 정책 자체를 재사용 가능한 학습된 자산으로 만든다'는 점에서, 모델마다 매번 새로 탐색해야 하는 기존 혼합정밀도 방식과는 결이 다른 접근이다."
    source_url: "https://arxiv.org/abs/2603.17891"
