  - title: "OffQ: 회전-오프셋으로 이상치를 흡수해 LLM을 W4A4KV4까지 양자화하는 기법"
    type: "논문"
    summary: "OffQ는 LLM 활성화값의 이상치(outlier) 문제를 다루는 양자화 전처리 기법으로, top-1 PCA로 활성화값 내 저차원 이상치 부분공간을 찾아낸 뒤 회전(rotation)을 통해 그 크기를 단일 채널로 집중시키고, 이 채널의 크기를 공유 오프셋(offset)으로 변환해 흡수함으로써 활성화값의 표준편차 자체를 줄인다. 기존 AWQ·SmoothQuant류가 스케일링으로 이상치를 '분산'시키는 접근이었다면 OffQ는 이상치를 아예 오프셋으로 '제거'하는 방향이라는 점이 다르며, 이를 통해 균일 격자·균일 정밀도라는 배포 친화적 방식으로도 W4A4KV4(가중치·활성화·KV캐시 모두 4비트) 양자화가 가능해진다는 것을 보여준다. 이상치 처리 방식 자체의 계보(스무딩→클러스터링→오프셋)를 이해하는 데 유용한 사례다."
    source_url: "https://arxiv.org/abs/2606.07116"
  - title: "Colinearity Decay: 사후 보정이 아니라 학습 단계에서 ViT를 양자화 친화적으로 만드는 구조적 정규화"
    type: "논문"
    summary: "비전 트랜스포머(ViT) 양자화의 근본 딜레마는 활성화 이상치를 강하게 억제하면 정밀도(FP) 정확도 자체가 떨어지고, 약하게 억제하면 양자화 후 정확도가 떨어진다는 것이다. 이 논문은 트랜스포머 블록 내 순서가 있는 행렬 쌍(예: 인접 레이어 가중치) 사이의 '해로운 교차-행렬 정렬(colinearity)'을 벌점화하는 구조적 정규화 항 Colinearity-Decay(CD)를 제안한다. 아키텍처나 태스크 손실을 바꾸지 않고 학습 과정에서만 이상치를 완화하기 때문에 PTQ나 활성화 억제형 QAT와는 다른 층위에서 작동하며, '왜 비전 도메인의 양자화 친화성은 학습 시점에서부터 설계돼야 하는가'를 보여주는 사례로 LLM 중심의 최근 양자화 논의에 비-LLM 관점을 더해준다."
    source_url: "https://arxiv.org/abs/2605.01330"
  - title: "CodeQuant: 회전 스무딩만으로는 부족한 MoE 양자화, 클러스터링으로 이상치를 센트로이드에 흡수"
    type: "논문"
    summary: "Mixture-of-Experts(MoE) 구조는 저정밀 양자화 시 일반 LLM보다 이상치로 인한 정확도 저하가 더 심각한데, 이 ICLR 2026 논문은 학습 가능한 회전으로 활성화 이상치를 스무딩하면서 동시에 가중치 이상치는 미세 조정된 군집 중심(centroid)에 흡수시키는 통합 클러스터링-양자화 기법 CodeQuant를 제안한다. Phi-Mini-MoE, Qwen3-30B-A3B, DeepSeek-V2-Lite, Mixtral 8x7B 등 다양한 MoE 모델에서 추론 속도 향상과 메모리 절감을 동시에 확인했다는 점에서, 라우팅 구조를 가진 모델은 조밀(dense) 모델과 다른 양자화 실패 모드를 갖는다는 것을 보여준다."
    source_url: "https://arxiv.org/abs/2604.10496"
  - title: "Beyond FLOPs: LLM 프루닝의 FLOP 감소가 실제 하드웨어 가속으로 이어지지 않는 이유"
    type: "논문"
    summary: "양자화가 아닌 프루닝(pruning) 쪽에서, 서로 다른 프루닝 기법들이 이론적 FLOP는 동일하게 줄이더라도 실제 하드웨어에서의 추론 가속 폭은 커널 구현과 GEMM(행렬곱) 차원(M/N/K) 중 어느 것을 줄이느냐에 따라 크게 갈린다는 것을 체계적으로 벤치마킹한 논문이다. 프루닝 기법을 GEMM 중심 분류 체계로 재구성해 '구조적 희소성이 실제로 언제 가속으로 전환되는지'를 정리했는데, 이는 최근 다룬 'NPU가 항상 빠르지 않다'는 양자화 쪽 발견과 같은 맥락을 프루닝에 적용한 것으로, 압축 기법을 FLOP 절감량만으로 비교하는 관행 자체에 의문을 제기한다."
    source_url: "https://arxiv.org/abs/2606.09080"
