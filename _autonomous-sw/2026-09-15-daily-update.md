  - title: "DriveZero — 지각은 파운데이션 모델 증류로, 행동은 폐루프 강화학습으로, 서로 다른 방식으로 배운 뒤 하나로 합친다"
    type: "논문"
    summary: "대부분의 엔드투엔드 주행모델은 사람 운전 로그를 모방학습으로 통째로 학습하지만, 이 논문은 '지각(perception)'과 '행동(action)'이 근본적으로 다른 학습 체제를 필요로 한다는 전제에서 출발한다. 지각 모델 DriveVFM은 DINOv3·SigLIP2·SAM·Depth Anything V2 같은 동결된 비전 파운데이션 모델들을 태스크별 라벨 없이 하나의 백본으로 통합해 방대한 시각 데이터의 이점을 그대로 흡수하고, 행동 모델 DriveRL은 실주행 로그를 상호작용 가능한 폐루프 월드로 바꾼 뒤 PPO로 학습되는 특권적 교사 정책이 담당한다. 두 모델을 각자에게 맞는 방식으로 따로 프리트레인한 다음, 목표 조건을 다양하게 바꿔가며 롤아웃시킨 DriveRL 교사의 궤적을 카메라 전용 학생 플래너로 증류함으로써 로그 데이터에는 없는 다양한 목표-일관적 지도신호를 얻는다. 그 결과 사람 궤적 지도 없이도 NAVSIMv1·NAVSIMv2·폐루프 HUGSIM 벤치마크에서 SOTA를 달성했고, DriveRL 단독으로도 nuPlan 세 스플릿에서 로그 재생 전문가를 능가했다. 엔드투엔드 모델을 하나의 손실함수로 뭉뚱그려 학습시키던 기존 흐름과 달리 '행동은 모방이 아니라 보상으로, 지각은 라벨이 아니라 증류로'라는 이원화된 설계 철학을 제시한다는 점에서 모듈형-엔드투엔드 논쟁에 새로운 축을 더한다."
    source_url: "https://arxiv.org/abs/2609.06055"
  - title: "Horizon3D — 장거리에서 희박해지는 레이더 포인트를 '객체 키포인트의 가우시안'으로 압축해 카메라와 융합하다"
    type: "논문"
    summary: "기존 BEV 그리드 기반 레이더-카메라 융합은 근거리에서는 잘 작동하지만, 고속도로 트럭 주행처럼 장거리로 갈수록 레이더 포인트가 극도로 희박해지고 격자 전체를 균일하게 처리하는 방식이 계산을 낭비하면서 정확도가 급격히 떨어진다는 문제가 있다. Horizon3D는 레이더·카메라 특징에서 예측한 객체 키포인트 위치에만 성긴 가우시안 프리미티브를 초기화(KGGI)하고, 이를 객체 중심 성긴 융합(OCSF)으로 정제해 BEV 평면에 스플래팅함으로써 객체 단위의 정밀한 정보와 레이더의 성긴 BEV 컨텍스트를 결합한다. 시간축 정보도 장면 전체를 누적하는 BEV 경로와 개별 객체의 움직임을 전파하는 가우시안 경로로 이원화(DPTF)해, 장거리에서 고속으로 움직이는 물체를 놓치지 않도록 설계했다. 트럭 주행 데이터셋 TruckScenes에서 기존 최고 성능 대비 NDS +3.0, mAP +1.6을 기록하면서도 추론 속도는 경쟁력 있게 유지했다. '격자 전체를 조밀하게 채운다'가 아니라 '물체가 있을 법한 곳에만 표현력을 집중시킨다'는 접근은, PointPillars 이후 BEV 센서퓨전이 밀도 기반에서 희소·객체 중심 표현으로 옮겨가는 흐름을 장거리 시나리오에 적용한 구체적 사례다."
    source_url: "https://arxiv.org/abs/2606.31096"
  - title: "AutoScale — 합성 주행 데이터는 많이 섞는다고 좋은 게 아니라, '어떤 클러스터를 얼마나 섞을지'가 핵심이다"
    type: "논문"
    summary: "실차 주행 데이터는 라벨링 비용이 크고 특정 장면에 편중되어 있어 사실상 무한히 생성 가능한 합성 데이터와의 co-training이 매력적인 보완책으로 떠올랐지만, 이 논문은 합성 데이터를 있는 대로 다 섞어 넣는 방식이 오히려 비효율적이고 실데이터와의 분포 이동(distribution shift)을 일으킨다는 점을 문제로 삼는다. AutoScale은 그래프 정규화 오토인코더(Graph-RAE)로 주행 장면을 표현 공간에 임베딩하고, 클러스터 인식 경사상승(Cluster-GA)으로 각 클러스터가 학습에 실제로 기여하는 중요도를 추정·재가중한 뒤, 클러스터 기준 벡터 검색으로 가치 있는 샘플만 골라 학습 배치에 편입시키는 완전 자동화된 폐루프 데이터 엔진이다. NavSim 실험에서 제한된 예산 하에 더 적은 합성 샘플만으로도 단순 co-training이나 교차 도메인 베이스라인보다 나은 성능을 냈다는 결과는, 시뮬레이션·합성데이터 연구의 무게중심이 '더 그럴듯한 장면을 얼마나 많이 생성하느냐'에서 '생성된 데이터 중 무엇을 얼마나 학습에 섞을 것이냐'라는 데이터 큐레이션 문제로 옮겨가고 있음을 보여준다. 지금까지 다뤄온 시나리오 생성·재구성 방법론들과 달리 합성데이터 파이프라인의 '뒷단'인 믹싱·샘플링 전략에 초점을 맞췄다는 점에서 함께 볼 가치가 있다."
    source_url: "https://arxiv.org/abs/2605.21372"
