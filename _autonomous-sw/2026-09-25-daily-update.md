  - title: "미래 장면을 '생성'하지 않고 '정렬'만 한다 — RAF-VLA가 월드모델링 VLA의 비용을 줄이는 법"

    summary: "최근 VLA 기반 e2e 주행 모델들은 미래 주행 장면을 명시적으로 예측·생성하도록 학습시켜 플래닝에 유용한 내부 표현을 얻는 월드모델링 방식을 쓰는데, 이는 추가 학습 비용과 추론 지연을 동반한다는 문제가 있다. RAF-VLA는 미래 장면을 직접 생성하는 대신 정책의 은닉 상태를 미래 프레임 표현에 정렬시키는 Future-Aligned SFT만으로 같은 효과를 노리는 설계를 택했고, NAVSIM v1/v2에서 훨씬 적은 학습 샘플과 거의 0에 가까운 추론 오버헤드로 경쟁력 있는 플래닝 성능을 보였다. '표현을 어떻게 얻을 것인가'에서 생성(generation) 대신 정렬(alignment)을 택하는 관점은 향후 경량 VLA 설계에 시사하는 바가 크다."

    type: "논문"
    summary: "주행 월드모델은 기록된 로그를 넘어 반사실적(counterfactual) 데이터와 인터랙티브 시뮬레이션을 대규모로 생성할 잠재력이 있지만, 실제로 쓰려면 다양한 장면에 일반화되고 ego pose·HD맵·3D 박스 같은 제어 신호에 충실히 반응하며 여러 센서를 동기화 생성하고 반복 추론에서도 효율적이어야 한다는 조건을 모두 충족해야 한다. HelloWorld는 이질적인 비디오에서 얻은 폭넓은 시각·모션 사전지식을 점진적으로 주행 특화 생성 능력으로 좁혀가는 20억 파라미터 시스템으로, 블록-코절 생성 구조로 자기생성 컨텍스트에 적응해 순차 시뮬레이션을 수행하고 7개 카메라 RGB와 조건부 LiDAR를 동기화 생성하면서 few-step 증류로 실배치 가능한 속도까지 확보한다. 월드모델을 '그럴듯한 영상을 뽑는 연구용 데모'에서 '실제 데이터 파이프라인에 넣을 수 있는 시스템'으로 옮기려는 설계 철학을 잘 보여준다."
