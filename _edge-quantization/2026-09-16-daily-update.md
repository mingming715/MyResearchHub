LLM 가중치 양자화 논의에 가려져 있던, 시계열·센서 데이터를 다루는 온디바이스 순환 모델의 양자화 실패 지점을 짚었다는 점에서 이미지 중심이 아닌 도메인의 양자화 한계를 이해하는 데 참고할 만하다."

  - title: "4비트로 양자화하면 최적 아키텍처도 바뀐다 — NAS와 PTQ가 충돌하는 지점"
    type: "논문"
    summary: "하드웨어 인지형 NAS(Neural Architecture Search)에 양자화를 결합하려는 시도가 늘고 있지만, 이 논문은 사후 양자화(PTQ)가 NAS가 찾아낸 파레토 프론티어 자체를 얼마나 뒤흔드는지가 제대로 규명되지 않았다고 지적한다. NAS-Bench-201의 전체 15,625개 아키텍처에 대해 INT4 PTQ가 파레토 공간을 실제로 어떻게 재배열하는지 형식적 안정성 지표로 정량화하고, 양자화된 라벨로 직접 학습시킨 서로게이트보다 오히려 풀프리시전 데이터로 학습한 서로게이트가 양자화 도메인의 파레토 공간을 더 잘 커버한다는 반직관적 결과를 보인다. '양자화를 고려해 탐색 루프를 설계하면 무조건 유리하다'는 통념에 의문을 던지며, NAS·프루닝 등 타 경량화 기법과 양자화의 상호작용을 이해하는 데 중요한 사례다."

  - title: "KV 캐시를 넘어선 새로운 병목 — 선형 어텐션의 순환 상태를 저비트로 압축하기"
    type: "논문"
    summary: "Gated DeltaNet(GDN)이나 Kimi Delta Attention(KDA) 같은 선형 어텐션 계열 모델은 시퀀스 길이에 비례해 커지는 KV 캐시 대신 고정 크기의 순환 상태(recurrent state)를 사용해 메모리 문제를 완화하지만, 이 상태 역시 보통 FP32로 저장되어 메모리 대역폭 병목을 그대로 물려받는다. 저자들은 이런 순환 상태에 대한 사후 양자화를 처음으로 체계적으로 연구했다고 밝히며, 균일 양자화는 INT8/FP8에서도 복잡한 추론 과제 정확도를 떨어뜨리고 INT4/NVFP4에서는 거의 무너진다는 점을 확인한 뒤, 오차가 소수의 특정 채널에 집중되고 채널별 감쇠 강도가 프롬프트와 무관하게 안정적이라는 두 패턴을 활용한 DAMP 기법을 제안한다.
