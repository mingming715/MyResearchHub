    summary: "유로NCAP이 2009년 등급제 도입 이래 가장 큰 개편을 2026년부터 적용하기 시작했다. 기존의 개별 항목 평가 대신 안전운전, 충돌회피, 충돌보호, 사고 후 안전이라는 4개 스테이지(세이프티 박스)를 각 100점 만점으로 채점하고, 2026~2027년은 소프트랜딩 기간을 두어 2028년부터 전 스테이지 일정 비율 이상 달성을 5스타 조건으로 강제한다. 특히 운전자 모니터링에 상당한 배점을 배정해 실시간 시선·머리 추적과 약물·알코올 손상 감지, 무반응 시 자동 정차 기능까지 요구하고, 화면 대신 물리 버튼(방향지시등, 비상등, 경적, 와이퍼, 이콜)을 다시 의무화했다. 학습자 입장에서 중요한 지점은 실제 개발 제약인데, 위험회피 정면 시나리오 시험 속도가 크게 올라가면서 신규 시험 장비가 필요해졌고, 이번이 처음으로 가상(시뮬레이션) 시험 데이터를 인증 근거로 인정받는 사이클이라 실차-시뮬레이션 상관성 검증 부담이 새로 생겼다. 즉 표준 하나의 개정이 크래시랩 인프라 투자, HMI 설계(물리버튼 회귀), 시뮬레이션 신뢰성 검증까지 연쇄적인 개발 제약을 만든 사례다."

  - title: "일본 MLIT, UNECE 틀에 없는 레벨2++ 인증 체계를 별도로 만드는 이유"

  - title: "ISO 26262 + SOTIF + UL 4600, 서로 다른 세 표준을 하나의 개발 워크플로로 묶으려는 시도"
    type: "논문"
    summary: "2026년 초 ScienceDirect에 게재된 이 논문은 자율주행 개발에서 부품 고장을 다루는 ISO 26262, 고장은 없지만 성능 한계로 위험해지는 상황을 다루는 SOTIF(ISO 21448), 그리고 전체 안전 사례(safety case)를 요구하는 UL 4600을 하나의 실행 가능한 워크플로로 통합한다. 구체적으로 STPA와 HARA를 하나의 위험분석·ASIL 매핑 절차로 결합하고 SOTIF의 기능부족(functional insufficiency) 위험요소를 ISO 26262 안전목표에 직접 연결한 뒤, 이를 레벨2 어댑티브 크루즈컨트롤+차선유지 시스템에 실제 적용해 검증했다. 이 논문이 의미 있는 이유는 실무에서 각 표준별 안전팀(기능안전 HARA팀, SOTIF 시나리오팀, UL4600 안전사례팀)이 사실상 따로 작업하며 중복과 누락이 발생하는 문제를 정면으로 다루기 때문으로, 표준 각각을 이론적으로 아는 것과 표준 세 개를 실제 하나의 개발 프로세스로 엮는 것 사이의 간극을 메우는 구체적 레시피를 제공한다는 점에서 실무형 자료로서 가치가 있다."
    source_url: "https://www.sciencedirect.com/science/article/pii/S259019822500510X"
  - title: "EU AI Act 고위험 시한 연기, 자동차 임베디드 AI는 2028년으로 미뤄지다"
    type: "뉴스"
    summary: "2026년 7월 발효된 EU 디지털 옴니버스 규정이 AI Act의 고위험 시스템 의무 시한을 연기했다. 독립형 고위험 시스템(Annex III)은 2026년 8월에서 2027년 12월로, 그리고 자율주행 인지·판단·제어나 운전자 모니터링처럼 기존 자동차 안전 법규에 이미 포함된 제품에 내장된 AI(Annex I)는 2027년 8월에서 2028년 8월로 미뤄졌다. 반면 투명성 표시 의무, 범용AI(GPAI) 제공자 의무, 금지행위 조항은 원래 일정대로 유지된다. 학습자에게 중요한 포인트는 이것이 규제가 사라진 것이 아니라 유예된 것이라는 점인데, HARA를 AI 특유의 실패모드(데이터 분포 변화, 적대적 입력 등)까지 확장하거나 학습 데이터 거버넌스 체계를 구축하는 작업은 수년이 걸리는 엔지니어링 과제이기 때문에, 법적 시한이 2028년으로 늦춰졌다고 해서 ISO 26262/SOTIF 프로세스에 AI 거버넌스를 통합하는 준비를 늦출 이유는 되지 않는다는 것이 이번 연기가 주는 실질적 교훈이다."
    source_url: "https://labs.cloudsecurityalliance.org/research/csa-research-note-eu-ai-act-high-risk-deadline-omnibus-20260/"
