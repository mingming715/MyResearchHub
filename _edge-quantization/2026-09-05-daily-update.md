  - title: "SCULPT: PTQ가 아니라 '학습 단계'에서 활동값 분포를 미리 다듬어 저비트 양자화를 준비시키는 방법"
    type: "논문"
    summary: "엣지 비전 모델을 저비트 PTQ로 배포하려 할 때 흔히 겪는 문제는, 일반적인 FP32 학습이 만들어내는 활동값(activation) 분포가 두꺼운 꼬리(heavy-tailed)를 가져서 극단치를 그대로 보존하면 양자화 구간 대부분이 드물게 나타나는 이상치에 낭비되고, 반대로 강하게 클리핑하면 정보 손실이 커진다는 딜레마다. 기존 해법은 QAT로 학습 복잡도와 비트폭 종속성을 감수하거나, 학습 후 모델을 사후 보정하는 고급 PTQ 절차에 의존해왔다. SCULPT는 이 문제를 학습 시점에서 선제적으로 해결하는 접근으로, 활동값의 왜도(skewness)와 첨도(kurtosis)를 억제하는 토폴로지 인지 정규화 항과, 배포에 적합한 클리핑 경계를 스스로 학습하는 안정적인 백분위수 기반 클리핑 메커니즘을 결합해, 통상적인 FP32 파인튜닝 과정 중에 모델이 PTQ에 '준비된' 활동값 분포를 갖도록 만든다. QAT 없이도 PTQ 친화적인 모델을 얻을 수 있다는 점에서, PTQ와 QAT 사이의 경계를 흐리는 실용적인 변형 기법이다."
    source_url: "https://arxiv.org/abs/2609.01743"
  - title: "LLM 양자화 손상은 소수의 '결정적 레이어'가 아니라 전체에 걸쳐 확산되어 있다는 인과적 분석"
    type: "논문"
    summary: "PTQ로 LLM을 서빙 비용을 낮출 때 정확도 손실은 균일하지 않고 모델마다 다르게 나타나는데, 이 논문은 추가 정밀도 예산을 어디에 배분해야 손상을 가장 잘 회복할 수 있는지를 인과적 혼합 정밀도 개입(causal mixed-precision intervention)을 정답 기준 삼아 4개 아키텍처 계열, 9개 공개 가중치 모델에 걸쳐 검증한다. '손상은 특정 태스크 회로에 있다', '연산이 몰리는 곳에 있다', '가중치 통계적 특이점에 있다'는 세 가지 직관적 가설을 모두 시험했지만 어느 것도 어떤 레이어가 정밀도 복원의 혜택을 받는지 안정적으로 예측하지 못했고, 대신 손상 회복은 '확산적'이어서 9개 모델 중 8개는 손상의 75%를 회복하는 데 대략 절반의 레이어가 필요했다(Qwen3-8B만 예외적으로 손상이 집중됨). 즉 같은 예산이라면 소수의 '위험 레이어'에 정밀도를 몰아주기보다 전역에 걸쳐 더 세밀하게 분산 배분하는 편이 낫다는 결론으로, 믹스드 프리시전 양자화 설계 원칙에 실증적 근거를 더한다."
    source_url: "https://arxiv.org/abs/2609.01587"
  - title: "'압축이 잘 됐다고 배포도 잘 되는 건 아니다' — 프루닝·양자화·증류를 실제 GPU/CPU/라즈베리파이에서 비교한 실증 연구"
    type: "논문"
    summary: "이 연구는 언어·이미지 경량 모델을 압축하는 다수의 최신 기법을 실제 GPU, CPU, Raspberry Pi 하드웨어에 배포해 QA(SQuAD)와 이미지 세그멘테이션 태스크에서 성능을 측정함으로써, 압축률이나 벤치마크 정확도만으로는 실제 배포 성능을 예측할 수 없다는 것을 구체적 수치로 보여준다. 예컨대 Q5_K_M GGUF 양자화는 SQuAD F1 93.85를 유지하는 반면, 동일 정밀도에서 1% 비율의 구조적 프루닝은 F1을 16점이나 깎아먹었고, 더 흥미롭게는 프루닝이 k-quant 슈퍼블록 정렬을 깨뜨려 저장된 체크포인트 크기를 오히려 21~49% '부풀리고' 출력이 길어지고 형식을 덜 지키게 되어 라즈베리파이 지연시간을 최대 3.4배까지 늘리는 역설적 결과를 신경망 흐름 그래프 분석과 prefill/decode 단계별 지연시간 분해로 설명한다. 어떤 단일 기법도 모든 태스크에서 우위를 갖지 않는다는 결론은, 09-03/09-04에 다룬 '프루닝 vs 양자화vs조기종료' 비교 연구에 이어 압축 기법 선택이 하드웨어·태스크에 강하게 의존적임을 재확인한다."
    source_url: "https://arxiv.org/abs/2608.15693"
