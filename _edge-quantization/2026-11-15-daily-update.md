    type: "개념정리"
    summary: "지금까지 다룬 양자화 기법 대부분은 LLM이나 ViT처럼 입력이 모델을 한 번 통과하는 구조를 전제로 한다. 반면 디퓨전 모델은 수십~수백 번의 디노이징 스텝을 반복하면서 매 스텝마다 활성값의 분포 자체가 달라지고, 한 스텝에서 생긴 양자화 오차가 다음 스텝으로 누적되는 독특한 문제를 안고 있다. 이 리뷰는 U-Net 기반과 Diffusion Transformer(DiT) 기반 디퓨전 모델 각각에 대해 PTQ와 QAT 방법들을 분류하고, 시간축을 고려한 캘리브레이션이나 LoRA 기반 QAT(EfficientDM 등) 같은 대응책들을 정리한다. 토이 사례가 아니라 무조건/클래스조건/텍스트조건 이미지 생성까지 벤치마크를 다뤄, 엣지에서 이미지·비디오 생성 모델을 돌리려는 사람에게 이 하위 분야가 LLM 양자화와 어디서 갈라지는지 보여주는 지도 역할을 한다."

  - title: "활성값이 아니라 '시간축 변화량'을 양자화하라 — MoDiff가 디퓨전 모델을 8비트에서 3비트까지 내린 방법"
    type: "논문"
    summary: "디퓨전 모델의 각 디노이징 스텝에서 나오는 활성값은 범위가 넓고 이상치가 많아, 단순히 스텝별로 양자화하면 비트를 낮출수록 품질이 급격히 무너진다. 위에서 정리한 '시간축에 따라 분포가 바뀌고 오차가 누적된다'는 문제에 대한 구체적인 해법으로, MoDiff는 각 스텝의 활성값 자체가 아니라 인접한 두 스텝 사이의 '변화량(temporal difference)'을 양자화한다. 변화량은 원래 활성값보다 범위가 좁고 이상치가 적어 저비트 양자화에 더 유리하고, 여기에 스텝을 거치며 쌓이는 오차를 보정하는 모듈을 추가해 누적 오차 문제까지 함께 다룬다. CIFAR-10과 LSUN에서 PTQ 기준 활성화 양자화를 8비트에서 3비트까지 내려도 성능 저하가 없었다는 결과(ICML 2025 채택, 자체 보고)는, '캐싱'이나 '가지치기'와는 별개로 디퓨전 모델 특유의 시간적 구조를 이용하는 압축 축이 따로 있음을 보여준다."
    source_url: "https://arxiv.org/abs/2506.22463"

    type: "논문"
    summary: "온디바이스 이미지 생성 앱은 베이스 모델 하나에 스타일·작업별 LoRA 어댑터를 여러 개 갈아 끼우는 방식으로 진화하고 있는데, 각 LoRA를 따로 양자화하면 스케일과 제로포인트가 서로 달라져 하나의 정적(static) 추론 그래프에 끼워 넣을 수 없다는 문제가 생긴다(지난주 다룬 Quant.npu의 '완전 정적 양자화' 전제와 정면으로 충돌하는 지점이다). 삼성 소속 연구진이 제안한 QUAD는 LoRA 가중치를 컴파일 시점에 그래프에 박아 넣는 대신 런타임 입력으로 다루고, '양자화 민감도 점수'로 기준(anchor) LoRA를 하나 고른 뒤 나머지 LoRA들을 증류로 그 양자화 프로파일에 맞춰 정렬시킨다. INT8 양자화와 증류 이후에도 FID·LPIPS·SSIM·PSNR 같은 생성 품질 지표가 유지됐다고 자체 보고했으며(제3자 검증은 아직 없음), 이 구조가 맞다면 베이스 모델을 재컴파일하지 않고도 새 LoRA를 OTA로 내려받아 바로 쓸 수 있다는 실용적 함의가 크다."
    source_url: "https://arxiv.org/abs/2603.29535"
  - title: "이미지가 아니라 '소리'다 — Edge-ASR이 측정한 음성인식 모델의 3비트 양자화 한계"
    type: "논문"
    summary: "지금까지 이 카테고리에서 다룬 비-이미지 영역 사례는 주로 LiDAR 포인트클라우드였는데, 음성인식(ASR)도 활성값 통계와 타깃 하드웨어(고정소수점 DSP 가속기)가 완전히 다른 별개의 영역이다. 퀄컴 AI 리서치가 공개한 Edge-ASR는 SmoothQuant·AWQ·OmniQuant 등 PTQ 기법 8종을 Whisper와 Moonshine 두 모델 계열(각각 Tiny~Small, Tiny~Base 크기)에 적용해 7개 데이터셋에서 비교한 벤치마크 논문이다. 핵심 결과는 고급 PTQ 기법을 쓰면 3비트까지 낮춰도 평균 단어 오류율(WER) 저하가 0.5% 미만이면서 모델 크기와 연산량은 65% 넘게 줄었다는 것으로, 저자들은 이를 ASR 모델에 대한 3비트 양자화 타당성을 여러 모델·여러 데이터셋에서 처음으로 검증한 사례라고 설명한다. GPU가 아니라 모바일 DSP처럼 정수 고정소수점 연산만 지원하는 가속기를 염두에 둔 설계라는 점에서, 온디바이스 추론 최적화 논의를 음성 도메인까지 넓혀 볼 가치가 있다."
    source_url: "https://arxiv.org/abs/2507.07877"
