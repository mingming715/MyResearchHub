    type: "논문"
    summary: "RISC-V가 ISO 26262 ASIL-D 인증 사례까지 나올 정도로 자동차용 임베디드 컴퓨팅 플랫폼으로 자리잡고 있지만, 실제 인증 비용의 대부분은 진단 커버리지 분석, 툴체인 검증, 결함 주입 캠페인, 안전성 케이스 문서화처럼 반복적이고 인건비 집약적인 작업에서 발생한다는 문제의식에서 출발한 논문이다. 저자들은 RISC-V 채택의 인증 비용 대비 이점을 정량화하는 경제성 프레임워크, LLM·지식 그래프·강화학습·그래프신경망을 인증 병목 구간별로 매핑한 ML 보조 인증 프레임워크, 플랫폼의 인증 성숙도를 5단계로 평가하는 RISC-V Safety Maturity Model(RSMM)을 제안하고 ASIL-D 등급 자동비상제동(AEB) ECU 사례 연구로 검증한다. 이는 자율주행 SoC/NPU 설계에서 연산 효율만큼이나 '인증 가능성'이 아키텍처 선택을 좌우하는 현실을 잘 짚어준다. 오픈 ISA로 커스텀 NPU/가속기 설계의 자유도를 얻으려는 진영이 안전 인증이라는 병목을 어떻게 넘을지 고민할 때 참고할 만한 로드맵이다."

  - title: "차량 센서 지연(staleness)에 강건한 센서 퓨전 기법, Zoox 연구진 발표"
    type: "논문"
    summary: "자율주행 차량에서는 카메라·라이다·레이더가 서로 다른 처리 지연 시간을 가지기 때문에 실제 주행 환경에서는 센서 데이터가 완벽히 동기화되지 않고 지연된(stale) 상태로 퓨전 모델에 들어오는 경우가 흔하며, 이 시간적 어긋남이 객체 상태 추정과 경로 예측 정확도를 크게 떨어뜨린다는 문제를 다룬다. Zoox 연구진은 라이다·레이더의 포인트마다 카메라 기준 타임스탬프 오프셋을 피처로 추가하고, 실제 배포 차량에서 관측되는 지연 패턴을 모사하는 데이터 증강 기법을 결합한 모델-비종속적 접근을 제안했다. 기존 모델은 센서 하나만 지연돼도 성능이 크게 저하됐지만, 제안 기법은 동기화된 조건과 지연된 조건 모두에서 일관되게 좋은 성능을 유지했다. 이는 GMSL·MIPI A-PHY 같은 물리 계층 동기화 표준만으로는 해소되지 않는, 소프트웨어 단에서의 '동기화 오차 흡수' 설계가 실제 양산 차량 퍼셉션 스택에서 왜 중요한지를 보여주는 사례다."
    source_url: "https://arxiv.org/abs/2506.05780"
  - title: "GNSS 없이 라이다 다중 센서를 동기화하는 레이저 펄스 기반 타이밍 기법"
    type: "논문"
    summary: "대부분의 다중 센서 시스템은 GNSS가 제공하는 클록으로 소프트웨어적 시간 동기화를 수행하지만, GNSS 신호 품질에 따라 정확도가 흔들리고 위성 신호가 끊기는 터널·도심 협곡 등에서는 아예 동작하지 않는 한계가 있다. 이 논문은 라이다 스캐너의 레이저 펄스에 동기화된 전기 펄스를 타이밍 소스로 직접 사용해 MCU 타이머를 구동하는 LPTS(Laser Pulse-driven Time Synchronization) 기법을 제안하며, 0.1μs 수준의 타이밍 정확도로 위치·자세 시스템(POS) 데이터와 레이저 스캐너 데이터를 보간 방식으로 정밀 정합한다. GNSS 의존도를 낮추면서도 하드웨어 수준의 결정론적 타임스탬프를 확보한다는 점에서, PTP 기반 이더넷 동기화나 GMSL의 타임스탬프 임베딩과는 다른 축의 해법이다. 소프트웨어 프로토콜에만 의존하지 않고 센서 자체의 물리적 신호를 타이밍 기준으로 삼는 하드웨어 설계 사례로, 특히 GNSS 취약 환경의 안전성을 고려하는 엔지니어에게 참고가 된다."
    source_url: "https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12737195/"
