    type: "논문"
    summary: "도구를 호출하는 LLM 에이전트는 도구가 반환하는 환경 상태(웹페이지, 파일, API 응답 등)에 공격자가 몰래 심어둔 지시문에 취약한데, 지금까지의 연구는 사람이 직접 구현하거나 재사용한 소수의 환경, 확률적인 LLM 시뮬레이션, 미리 정해진 주입 위치에 의존해 왔기 때문에 보안 연구를 다양한 도메인으로 확장하기 어려웠다. ToolHazard는 환경 시뮬레이터·공격자 에이전트·사용자 시뮬레이터 세 구성요소로 실행 가능한 상태기반(stateful) 환경을 자동 합성하고, 공격 지점을 스스로 탐색해 도메인에 특화된 페이로드를 생성하며, 상태에 근거한 장기 과제(long-horizon task)까지 구성한다. 이렇게 만든 ToolHazard-Bench로 평가한 결과 (1) 에이전트는 여전히 환경 프롬프트 인젝션에 광범위하게 취약하고, (2) 주입된 지시문이 관찰 기록의 앞쪽에서 일찍 등장하고 끝부분에 가까이 배치될수록 공격이 더 잘 먹히며, (3) ToolHazard가 자동 합성한 대규모 적대적 데이터로 정렬(alignment) 학습을 시키면 AgentDojo 등 다른 벤치마크에서도 보안이 개선되면서 정상 과제 수행 능력은 유지된다는 점을 확인했다. 최근 다뤄온 순수 아키텍처·해석성 논문들과 달리, 이 논문은 '에이전트가 도구를 쓴다'는 설계 패턴 자체가 만들어내는 공격 표면을 체계적으로 정량화하고 방어까지 자동화하려는 시도로, 도구 사용을 다루는 에이전트 설계자라면 눈여겨볼 만하다."
