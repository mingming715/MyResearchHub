  - title: "RL로 다듬은 모델, 양자화만 하면 왜 무너질까 — QAD가 찾은 답"
    type: "뉴스"
    summary: "NVIDIA가 Nemotron 3.5 Lightning 모델을 NVFP4(4비트 부동소수점)로 양자화해 실제 배포하면서 겪은 문제와 해법을 기술 블로그로 공개했다. SFT, 강화학습(RL), 모델 병합 등 여러 단계의 post-training을 거친 모델에 기존 방식의 양자화 인식 학습(QAT)을 그대로 적용하면 RL로 어렵게 얻은 추론·코딩 능력이 오히려 붕괴하는 현상을 발견했다는 점이 핵심이다. 이를 해결하기 위해 원본 BF16 모델을 교사로 두고 KL발산 손실로 학생 모델을 학습시키는 Quantization-Aware Distillation(QAD)을 적용해, 데이터 품질이나 커버리지에 덜 민감하면서도 거의 BF16 수준의 정확도를 회복했다. 결과적으로 모델 크기를 66GB에서 22GB로 줄이고 처리량을 최대 4배 높이면서도 정확도 손실을 최소화했다. 실제 프로덕션 LLM에서 '언제 표준 QAT가 실패하고 왜 증류 기반 접근이 필요한가'를 구체적 수치로 보여준 사례라서, PTQ/QAT 변형과 정확도 완화 기법을 공부하는 사람에게 실무적 시사점이 크다."
    source_url: "https://developer.nvidia.com/blog/developing-nemotron-3-5-lightning-nvfp4-with-qad-using-nvidia-model-optimizer/"
  - title: "PTQ의 숨은 약점, 캘리브레이션 데이터를 모델 스스로 다시 만들게 하다"
    type: "논문"
    summary: "PTQ 정확도를 좌우하는 핵심 병목 중 하나는 알고리즘이 아니라 소수의 캘리브레이션 샘플이 실제 추론 시 활성화 분포를 제대로 대표하지 못한다는 점이다. FAQ(Family-Aware Quantization)는 양자화 대상 모델과 같은 개발 계보('패밀리')의 더 큰 LLM에 원본 캘리브레이션 샘플을 입력시켜, 지식 체계가 일관된 고품질 캘리브레이션 데이터를 새로 생성하는 방법을 제안한다. 같은 패밀리의 모델들이 활성화 패턴에서 상당히 일치한다는 관찰에 기반해, 별도의 대규모 데이터 수집 없이도 양자화 파라미터의 편향을 줄일 수 있다는 것이 핵심 주장이다. GPTQ·AWQ 같은 알고리즘 자체 개선이 아니라 '캘리브레이션 데이터의 품질'이라는 상대적으로 덜 조명된 각도에서 PTQ 오차를 줄이려는 접근이라 원리를 이해하는 데 도움이 된다. 다만 같은 패밀리의 더 크고 강력한 모델이 별도로 있어야 한다는 전제조건이, 실제 온디바이스·엣지 배포 시나리오에서 어떤 제약으로 작용할지는 비판적으로 볼 필요가 있다."
    source_url: "https://arxiv.org/abs/2601.11200"
  - title: "레이어 단위로 나누던 정밀도, 이제 뉴런 하나하나가 스스로 정한다"
    type: "논문"
    summary: "기존 혼합정밀도 양자화(mixed-precision quantization)는 레이어나 채널 단위로 비트폭을 배분하는 굵은 granularity에 의존해왔는데, 이 연구는 각 뉴런이 학습 중 스스로 이산적인 정밀도를 결정하는 '뉴런 단위 혼합정밀도 QAT(NMP-QAT)'를 제안한다. 낮은 비트에서 출발해 학습 신호가 실제로 필요로 할 때만 비트폭을 확장하는 방식으로, 미분가능한 대체 함수와 straight-through estimator를 활용하면서도 추론 시점의 계산 그래프는 완전히 이산적인 정밀도로 유지한다. 가중치뿐 아니라 활성화에도 이 방식을 적용해 메모리 이동량 자체를 줄인다는 점이 특징이며, 자원이 극히 제한된 엣지 기기 배포를 염두에 두고 설계됐다. 정밀도 배분을 사전에 전역적으로 정해두는 기존 접근과 달리 학습 과정에서 파라미터 단위로 세밀하게 적응시킨다는 점에서 정확도-효율 트레이드오프를 재구성하려는 최신 흐름을 잘 보여준다. 다만 뉴런별로 서로 다른 정밀도를 갖게 되면 실제 NPU 등 하드웨어에서 이를 효율적으로 실행할 수 있는지, 즉 이론적 이득이 실제 가속기 이득으로 이어지는지는 별도 검증이 필요해 보인다."
    source_url: "https://arxiv.org/abs/2605.25054"
