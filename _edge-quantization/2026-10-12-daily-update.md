  - title: "레이블도 블록 단위 보정도 없이 — 스테이블 디퓨전으로 '가짜 데이터'를 만들어 ViT를 통째로 양자화하다"
    type: "논문"
    summary: "비전 트랜스포머(ViT)의 PTQ(post-training quantization)는 보통 블록 단위로 순서대로 보정(calibration)을 진행하는데, 이 방식은 블록 간 상호작용으로 생기는 오차를 반영하지 못한다는 구조적 한계가 있다. 2026년 2월 공개된 이 논문은 레이블 없이 모든 레이어를 한꺼번에 최적화하는 end-to-end 방식으로 이 문제를 풀면서, 동시에 '보정용 실제 데이터가 없을 때 무엇으로 대체할 것인가'라는 또 다른 난제에는 학습된 멀티모드 프롬프트로 Stable Diffusion Turbo를 유도해 보정 이미지를 직접 생성하는 방법을 제시한다. ViT-small 기준 단일 GPU에서 약 1시간이면 끝나는 경량 보정 과정으로 W4A4·W3A3에서 최고 수준의 정확도를 보고하며, ViT·DeiT·Swin-T를 극저비트인 W1.58A8까지 내려도 정확도를 유지한 첫 사례라고 주장한다. 실제 데이터 없이 생성 모델로 '정확도 손실 없는' 가짜 보정 데이터를 만든다는 발상이, 데이터 접근이 제한된 온디바이스 양자화 파이프라인에 실질적인 선택지를 넓혀준다는 점에서 눈에 띈다."
    source_url: "https://arxiv.org/abs/2602.18861"
  - title: "디퓨전 모델을 2~4비트까지 내리면 왜 깨지는가 — MPQ-DMv2가 짚은 세 가지 약점과 그 처방"
    type: "논문"
    summary: "디퓨전 모델의 저비트 양자화는 LLM이나 ViT와는 다른 종류의 어려움을 겪는데, 이 논문은 기존 기법들이 2~4비트 구간에서 무너지는 이유를 양자화기 설계가 이상치(outlier)를 제대로 다루지 못하는 점, 초기화가 최적이 아닌 점, 최적화 전략 자체가 약한 점 세 가지로 짚어낸다. MPQ-DMv2는 여기에 잔차(residual) 브랜치를 추가해 혼합정밀도 양자화의 표현력을 높이고, 동시에 시간적 증류(temporal distillation)로 양자화된 모델이 매 디노이징 스텝에서 원본 모델과 비슷한 궤적을 따르도록 강제해 가장 낮은 비트 구간에서의 성능 저하를 줄인다. LLM 양자화에서 '어디에 이상치가 몰리는가'를 다루는 논의와 비슷한 문제의식을, 매 스텝마다 분포가 달라지는 디노이징 과정이라는 디퓨전 모델 고유의 조건 위에서 풀어낸 사례라, 이미지·비디오 생성 모델의 경량화가 LLM 양자화와 어떤 지점에서 같고 다른지를 비교해보는 데 참고할 만하다."
    source_url: "https://arxiv.org/abs/2507.04290"
