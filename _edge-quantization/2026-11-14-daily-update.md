    type: "논문"
    summary: "PTQ를 비트 수 관점에서 설계할 때 기존 방법들은 2비트·3비트·4비트처럼 정수 단위로만 비트를 배분했지만, 레이어마다 실제 최적 압축률은 그 사이의 '소수 비트(fractional bit)'에 걸쳐 있다는 것이 Q-Palette의 출발점이다. 트렐리스 코드 양자화기(가우시안 왜곡-레이트 한계에 가까운 정밀도)부터 더 단순한 벡터·스칼라 양자화기(더 빠른 추론)까지 정밀도-속도 트레이드오프가 서로 다른 양자화기 모음을 만들고, 레이어마다 어떤 양자화기를 쓸지와 레이어 퓨전 여부를 자원 제약 아래 함께 최적화하는 혼합 스킴 프레임워크를 제안한다. NeurIPS 2025 메인트랙에 채택되고 최적화된 CUDA 커널까지 공개했다는 점에서, '양자화 비트 수는 정수여야 한다'는 가장 기본적인 설계 전제를 재검토하게 하는 논문이다."

  - title: "이상치를 없애는 대신 '한곳에 몰아넣는다' — OffQ가 W4A4KV4까지 밀어붙인 방법"
    type: "논문"
    summary: "LLM 활성화 값은 일부 채널에 비정상적으로 큰 이상치가 몰려 있어, 가중치뿐 아니라 활성화와 KV캐시까지 4비트로 낮추면 성능이 급격히 무너지는 경우가 많다. OffQ는 top-1 PCA로 이상치가 모여 있는 저차원 부분공간을 먼저 찾아내고, 회전을 통해 그 이상치 에너지를 단 하나의 채널로 몰아넣은 뒤, 첫 행이 모두 1인 그룹 단위 아다마르 변환으로 이상치 크기만큼의 '상수 오프셋'으로 바꿔 균일 양자화기로도 다루기 쉽게 만든다. 커스텀 커널이나 고정밀도 폴백 채널 없이, 기존 W4A4KV4 파이프라인에서 거의 깨졌던 Qwen2.5 같은 모델까지 안정적으로 양자화했다는 결과는, '이상치를 어떻게 지울까'가 아니라 '이상치를 어디로 몰아넣을까'로 질문을 바꾸는 접근이 왜 통하는지를 보여준다."

  - title: "드래프트 모델 없이도 추측 디코딩이 된다 — DIAA가 룩업테이블로 엣지 LLM 속도를 올린 방법"
    type: "논문"
    summary: "추측 디코딩(speculative decoding)은 작은 '드래프트' 모델이 먼저 여러 토큰을 예측하고 큰 모델이 한 번에 검증해 생성 속도를 높이는 기법이지만, 드래프트 모델 자체가 추가 메모리를 요구하고 고정된 토큰 트리 구조 때문에 엣지 기기에서는 효율이 떨어진다는 한계가 있었다. DIAA는 별도의 드래프트 모델 대신 LLM이 과거에 생성한 토큰 기록을 캐싱하는 룩업테이블(LUT)만으로 후보 토큰을 뽑아내고, 이를 바탕으로 매 스텝 모양이 바뀌는 동적 토큰 트리를 구성해 병렬로 검증한다. NVIDIA Jetson 같은 실제 엣지 플랫폼에서 메모리 오버헤드를 거의 늘리지 않으면서 생성 속도와 지연시간 모두 기존 베이스라인을 앞섰다는 결과는, 온디바이스 추론 최적화가 양자화·가지치기처럼 '모델을 깎는' 접근 말고도 디코딩 알고리즘 자체를 바꾸는 방향으로도 갈 수 있음을 보여준다."
    source_url: "https://ojs.aaai.org/index.php/AAAI/article/view/39789"
