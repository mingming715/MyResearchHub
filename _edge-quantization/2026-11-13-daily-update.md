  - title: "깊이를 자르면 깨지고, 너비를 자르면 느려진다는 딜레마 — COMPACT가 채널과 토큰을 같이 자른 이유"
    type: "논문"
    summary: "LLM을 가볍게 만들 때 레이어를 통째로 제거하는 깊이(depth) 가지치기는 속도는 빠르지만 정확도가 갑자기 뚝 떨어지고, FFN 채널 단위로 자르는 너비(width) 가지치기는 표준 트랜스포머 구조를 깨뜨려 별도의 추론 코드가 필요해지는 trade-off가 있었다. IJCAI 2026에 채택된 COMPACT(Common-token Optimized Model Pruning Across Channels and Tokens)는 둘 중 하나를 고르는 대신, 자주 쓰이는 토큰의 활성값만으로 FFN 채널 중요도를 매기고 드문 어휘 토큰과 FFN 채널을 동시에 잘라내는 학습 없는(training-free) 방법을 제안한다. Qwen2.5·LLaMA3·Gemma3(0.5B~70B)에서 검증한 결과 가지치기 비율이 올라갈수록 깊이 가지치기보다 훨씬 완만하게 성능이 저하되고, 특히 소형 모델에서는 MMLU·GSM8K 같은 어려운 과제에서 성능 붕괴 시점을 늦췄다고 보고한다. '어느 축을 자를 것인가'라는 양자택일 구도 자체를 깨고 토큰·채널을 함께 보는 접근이라, pruning 설계 공간을 한 단계 넓혀 보여주는 사례다."
    source_url: "https://arxiv.org/pdf/2509.06836"
  - title: "양자화 따로, 가지치기 따로 하지 않는다 — UniQL이 SSM·하이브리드 모델까지 한 번에 압축한 방법"
    type: "논문"
    summary: "온디바이스 LLM 압축에서 양자화와 저랭크/구조적 압축은 보통 순차적으로 따로 적용되는데, ICLR 2026에 채택된 UniQL은 이 둘을 '한 번의 post-training 패스'로 통합한 첫 방법이라고 주장한다. 클라우드에서 가중치 정렬·양자화 인식 SVD(quantization-aware SVD)·파인튜닝을 한 번에 수행해두면, 디바이스 쪽에서는 최대 35%까지 원하는 비율로 바로 가지치기를 적용할 수 있게 만든 구조다. 특히 SSM(Mamba2)과 트랜스포머-SSM 하이브리드(Nemotron-H, Bamba-v2)까지 포괄해 검증했다는 점이 핵심인데, 지금까지 양자화·압축 기법 논의가 대부분 순수 트랜스포머(비전·LLM)에 집중돼 있었던 것과 달리 아키텍처가 다양해지는 흐름(루프형/재귀형 트랜스포머, SSM 등)에 압축 기법이 따라가야 한다는 걸 보여준다. 저자들은 4~5.7배 메모리 절감과 2.7~3.4배 토큰 처리량 향상을, 15% 가지치기 기준 원본 대비 5% 이내 정확도 손실로 달성했다고 보고하며, 코드와 양자화된 모델도 공개했다."
    source_url: "https://arxiv.org/abs/2512.03383"
