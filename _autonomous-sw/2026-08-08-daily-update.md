  - title: "GraphBEV++: 센서 캘리브레이션 오차에 강건한 BEV 특징 정렬 프레임워크"
    type: "논문"
    summary: "BEV 퓨전은 라이다와 카메라 좌표를 하나의 격자에 투영해 합치는 방식인데, 실제 차량에서는 진동·온도 변화·시간 경과에 따라 두 센서 간 캘리브레이션이 미묘하게 어긋나는 일이 흔하다. 기존 BEVFusion·BEVFormer 계열 모델들은 대체로 캘리브레이션이 정확하다는 전제 위에서 설계되어, 이 오차가 조금만 커져도 성능이 급격히 무너지는 문제가 있었다. GraphBEV++는 이런 투영 오차를 '지역적 어긋남'과 '전역적 어긋남'으로 나누어 각각 다르게 대응하는데, LocalAlign-v2는 그래프 매칭으로 이웃 픽셀 단위 깊이 특징을 보정하고 GlobalAlign-v2는 LSS 기반 BEV에는 변형 가능한 오프셋 학습을, 쿼리 기반 BEV에는 노이즈를 일부러 주입했다가 제거하는 디퓨전 방식을 적용해 서로 다른 BEV 패러다임 모두에 호환되도록 설계했다. nuScenes 오정렬 노이즈 환경에서 BEVFusion 대비 mAP를 8.3%p 끌어올렸고 Bench2Drive·NAVSIM 폐루프 평가에서도 인식-예측-플래닝 전 구간에서 개선을 보여, '완벽한 캘리브레이션'이라는 실험실 가정을 깨고 실차 환경의 불확실성을 정면으로 다뤘다는 점에서 의미가 크다."
    source_url: "https://arxiv.org/abs/2606.16354"
  - title: "모방학습 이후: End-to-End 자율주행 모델의 포스트트레이닝 지형도 정리"
    type: "논문"
    summary: "E2E 자율주행 모델(VLA 포함)은 대부분 전문가 주행 데이터를 그대로 따라하는 모방학습(open-loop imitation)으로 학습되는데, 이 방식은 작은 실수가 누적돼도 복구 시나리오가 데이터에 거의 없고 안전성·승차감 같은 장기적 목표를 점 단위 라벨로는 담아낼 수 없다는 근본적 한계를 가진다. 이 논문은 이런 한계를 넘어서기 위해 등장한 다양한 '포스트트레이닝' 기법들을 감독 신호의 형태에 따라 지식 증류(distillation), 선호 기반 정렬(preference-based alignment), 강화학습(RL), 테스트타임 정제(test-time refinement) 네 갈래로 정리한 서베이다. 개별 신기법을 제안하기보다 LLM 분야의 SFT→RLHF 발전 경로를 자율주행에 빗대어, 왜 모방학습만으로는 부족한지와 각 포스트트레이닝 계열이 정확히 어떤 실패 모드(오차 누적, 희귀 회복 행동, 장기 목표 미반영)를 겨냥하는지를 구조적으로 짚어준다. 자율주행 SW 스택의 학습 목표 자체가 '얼마나 잘 따라하는가'에서 '폐루프 상황에서 얼마나 안전하고 매끄럽게 행동하는가'로 이동하고 있음을 보여주는 지형도라서, 최근 쏟아지는 RL/DPO/증류 계열 논문들을 하나의 틀로 이해하는 데 유용하다."
    source_url: "https://arxiv.org/abs/2607.08072"
  - title: "단일 스윕 라이다로 충분하다: 이중 Range-Voxel 표현 기반 3D 점유 예측"
    type: "논문"
    summary: "라이다 기반 3D semantic occupancy(점유) 예측은 포인트 클라우드가 원래 희소하고 불완전하기 때문에, 기존 방법들은 여러 프레임(멀티 스윕)을 쌓아 조밀한 정보를 확보하는 방식을 관행적으로 써왔다. 하지만 이 관행은 계산 비용을 늘릴 뿐 아니라 차량이 움직이는 동안의 포즈 변환 오차가 누적되어 오히려 강건성을 해치는 부작용이 있다. 이 논문은 멀티 스윕을 쌓는 대신 단일 스윕 포인트 클라우드에서 range-view(거리 영상 형태의 압축된 문맥 정보)와 voxel-view(다중 스케일 기하 정보)를 각각 인코딩한 뒤 양방향으로 융합하는 Dual Range-Voxel Representation(DRVR)을 제안해, '정보를 더 쌓기'보다 '가진 정보를 더 잘 짜내기'라는 설계 철학을 취한다. nuScenes-Occupancy에서 멀티 스윕 방법 대비 mIoU를 5.4%p 높이면서 동시에 2.1배 빨라졌다는 결과는, 지연시간과 강건성이 동시에 중요한 실차 배포 환경에 실질적 시사점을 준다."
    source_url: "https://arxiv.org/abs/2606.31688"
  - title: "CARLA-GS: 표현·추론·물리 시뮬레이션을 분리한 코너 케이스 합성 파이프라인"
    type: "논문"
    summary: "안전이 중요한 자율주행 모델을 검증하려면 실제 주행 데이터에는 거의 없는 위험한 코너 케이스가 필요한데, 이를 생성하는 문제는 사진처럼 보이는 장면을 만드는 시각적 표현, 어떤 상황이 위험한지 판단하는 의미적 추론, 차량이 물리적으로 실현 가능하게 움직이는 제어라는 서로 다른 성격의 세 하위 문제가 얽혀 있다. CARLA-GS는 이 세 문제를 하나의 거대 모델로 뭉뚱그리는 대신 모듈로 명확히 분리하는 설계를 택해, 실제 주행 데이터로부터 편집 가능한 3D 가우시안 장면을 복원하고 멀티에이전트 LLM이 장면을 읽어 위험한 상호작용과 의도 수준 경로를 생성하며 CARLA의 PID 컨트롤러가 이를 운동학적으로 실현 가능한 저수준 제어로 변환한 뒤 결과를 다시 가우시안 장면에 재투영해 에고 시점 영상으로 렌더링한다. Waymo Open Dataset 실험에서 의미상 의도와 물리적 타당성을 모두 만족하는 시공간적으로 일관된 코너 케이스 영상 생성을 보였으며, '주행 정책은 end-to-end로, 시뮬레이션 데이터 생성 파이프라인은 모듈형으로'라는 대비되는 설계 선택이 왜 합리적인지를 보여주는 사례라서 흥미롭다."
    source_url: "https://arxiv.org/abs/2607.07601"
