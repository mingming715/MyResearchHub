  - title: "모바일 NPU는 '동적'을 못 견딘다 — Quant.npu가 양자화를 통째로 정적으로 바꾼 이유"
    type: "논문"
    summary: "지금까지 다뤄온 PTQ 기법 대부분은 활성값(activation)의 최소·최대 범위를 추론 중에 그때그때 계산하는 '동적 양자화'를 전제로 발전해왔는데, 이 논문은 실제 모바일 NPU 하드웨어에서는 이것이 치명적인 오버헤드라고 짚는다. NPU는 런타임에 범위를 다시 계산하는 연산(예: 128개짜리 INT8 벡터의 최소·최대를 구하는 트리 리덕션) 자체를 지원하지 않거나 매우 비효율적으로 처리하도록 설계돼 있어, 동적 양자화 기법을 그대로 얹으면 하드웨어의 이점을 살리지 못한다는 것이다. Quant.npu는 그래서 양자화 파라미터와 회전 행렬(rotation matrix)을 학습 가능한 값으로 미리 고정해, 추론 중 재계산이 전혀 필요 없는 '완전 정적(fully static)' 정수 전용 파이프라인을 설계했고, 여기에 민감도 기반 혼합정밀도까지 더했다. 실제 모바일 NPU에서 기존 최고 수준 기법과 비슷한 정확도(평균 정확도 하락 2.58%p, perplexity 증가 1.23 수준)를 유지하면서 추론 지연을 최대 15.1% 줄였다고 보고한다(저자 자체 수치). 그동안 이 아카이브가 다뤄온 KV 캐시·회전 기반 PTQ 연구들이 주로 '어떻게 더 적은 비트로 정확도를 지킬까'를 물었다면, 이 논문은 '그 양자화 설계가 실제 NPU 명령어 집합과 호환되는가'라는, 알고리즘과 실리콘 사이의 간극을 정면으로 겨냥한 사례라는 점에서 온디바이스 추론 최적화 논의에 실무적으로 중요하다."
    source_url: "https://arxiv.org/abs/2605.20295"
  - title: "이미지용 PTQ를 라이다에 그대로 쓰면 왜 무너지나 — Point4Bit가 포인트클라우드에 맞춘 INT4"
    type: "논문"
    summary: "이미지 기반 비전 모델의 PTQ 기법은 보통 조밀하고 규칙적인 픽셀 그리드를 전제로 발전해왔지만, 복셀(voxel) 기반 포인트클라우드 3D 디텍터는 전경(foreground) 포인트가 극히 희소하고 배경이 대부분 비어 있어, 같은 양자화 기법을 그대로 적용하면 드문 전경 활성값의 정보가 양자화 과정에서 뭉개지기 쉽다. 그래서 지금까지 포인트클라우드 디텍터용 PTQ는 대체로 INT8 수준에 머물러 있었는데, Point4Bit(NeurIPS 2025)는 복셀 기반 3D 디텍터를 위한 범용 INT4 PTQ 프레임워크를 제시한다. 전경 구조 정보를 활용해 희소 활성값을 구간별로 나눠 양자화하는 'FA-PAQ'와, 그래디언트 기반으로 과업에 핵심적인 가중치만 선별해 정밀도를 지키는 'G-KWQ' 두 기법을 결합해, nuScenes의 CenterPoint-Voxel 기준으로 INT4에서도 정확도 하락을 1.5%포인트 이내로 묶었다고 보고한다(저자 자체 수치). 분류·세그멘테이션 과업에도 같은 프레임워크가 일반화된다고 밝힌 점도 특징이다. 이는 '양자화 기법은 도메인에 구애받지 않는다'는 암묵적 가정이 라이다·포인트클라우드처럼 희소하고 불균일한 비-이미지 데이터에서는 깨질 수 있다는 것을 보여주는 사례로, 에지 디바이스에 올라가는 센서 인식 스택 전체(카메라+라이다)의 경량화를 생각할 때 카메라 쪽 PTQ 노하우를 라이다에 그대로 옮길 수 없다는 경고로 읽을 수 있다."
    source_url: "https://proceedings.neurips.cc/paper_files/paper/2025/file/f1922bd718528ac3eab114eabbbfa7a0-Paper-Conference.pdf"
