  - title: "데이터를 더 모으는 게 아니라 '어디서 모을지'를 고른다 — MOSAIC이 스케일링 법칙을 데이터 선별에 쓴 방법"
    type: "논문"
    summary: "엔드투엔드 자율주행 모델 학습에서는 흔히 '로그를 더 많이 모으면 성능이 오른다'는 식으로 데이터 스케일링을 다뤄왔지만, 교외 주행과 혼잡한 도심 주행처럼 서로 다른 도메인이 똑같은 비율로 성능에 기여하지는 않는다. MOSAIC(NYU·NVIDIA·오타와대, CVPR 2026)은 데이터셋을 여러 도메인으로 쪼갠 뒤 각 도메인마다 개별 스케일링 법칙을 추정하고, '지금 추가하면 평가 지표를 가장 많이 끌어올릴 도메인'을 반복적으로 골라 학습 데이터 조합을 구성한다. 즉 데이터를 늘리는 문제를, 어떤 종류의 데이터가 아직 '덜 포화된' 상태인지를 찾는 최적화 문제로 바꾼 것이다. NAVSIM 기반 플래너 평가(EPDMS)에서 무작위·휴리스틱 베이스라인 대비 최대 80%까지 적은 데이터로 동등하거나 더 나은 성능을 냈다고 보고하는데, 이는 이번 주 다룬 SimScale(순수 시뮬레이션 스케일링)과 맞물려 '얼마나 많은 데이터'가 아니라 '어떤 데이터'가 자율주행 모델의 다음 성능 상한을 결정한다는 흐름을 보여준다."
    source_url: "https://arxiv.org/abs/2604.08366"
  - title: "트랜스포머로 BEV를 '계산'하는 대신, 점으로 '찍어서' 만든다 — GaussianCaR의 카메라-레이더 융합"
    type: "논문"
    summary: "BEVFusion류의 기존 카메라-레이더/라이다 융합은 대개 트랜스포머 기반 뷰 변환(view transformation)으로 각 센서의 특징을 BEV 평면에 투영하는데, 이 어텐션 연산 자체가 추론 비용의 상당 부분을 차지한다. GaussianCaR(ICRA 2026)은 뷰 변환기를 통째로 3D 가우시안 스플래팅으로 대체한다 — 카메라 픽셀과 레이더 포인트 각각을 위치·크기·방향·불투명도·의미 특징을 갖는 3D 가우시안으로 '들어 올린' 뒤, 이를 2D BEV 그리드에 직접 스플래팅해서 합성하는 방식이다. 학습 가능한 가우시안 파라미터가 센서별 불확실성(레이더의 낮은 각도 분해능, 카메라의 깊이 모호성)을 자연스럽게 흡수하도록 두고, 그 위에 멀티스케일 융합과 트랜스포머 디코더만 가볍게 얹는다. nuScenes BEV 세그멘테이션에서 기존 SOTA와 동등하거나 더 나은 IoU(차량 57.3%, 도로 82.9%)를 내면서도 추론 속도는 3.2배 빠르다고 보고하는데, 뷰 합성 기술인 가우시안 스플래팅이 '렌더링'이 아니라 '센서 융합의 중간 표현'으로 쓰일 수 있음을 보여준 사례라는 점에서 주목할 만하다."
    source_url: "https://arxiv.org/abs/2602.08784"
