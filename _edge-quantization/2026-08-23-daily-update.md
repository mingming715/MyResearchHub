  - title: "NPU가 GEMM은 잘해도 역양자화는 못한다 — T-MAN, 테이블 룩업 하나로 저비트 LLM 추론을 통째로 NPU에 올리다"
    type: "논문"
    summary: "NPU는 행렬곱(GEMM)에는 최적화돼 있지만 역양자화(dequantization)처럼 GEMM이 아닌 연산에는 취약해서, 저비트로 양자화한 LLM을 NPU에 올려도 오히려 CPU보다 느려지는 역설이 흔했다. T-MAN은 이 문제를 '저비트 값의 목표 연산 결과를 감당할 만한 크기의 테이블에 미리 인코딩해 둘 수 있다'는 통찰로 우회한다. 즉 역양자화를 포함한 하드웨어 미지원 연산을 테이블 룩업으로 대체하는 것인데, prefill과 디코딩 단계가 서로 상충하는 하드웨어 특성을 요구한다는 문제를 2단계 융합 테이블 기반 역양자화와 동시성 계층을 고려한 타일링으로 풀어 하나의 통일된 테이블 레이아웃을 설계했다. 그 결과 기존 NPU 추론 대비 prefill 1.4배, 디코딩 3.1배 속도 향상과 84%의 에너지 절감을 달성했고, 1/1.58비트 BitNet과 BitDistiller 계열 2비트 QAT 모델(Qwen-3, Llama-3)까지 지원해 Snapdragon 8G3에서 BitNet-2B-4T를 초당 50토큰으로 구동한다. 저비트 양자화 알고리즘 자체보다 '양자화된 모델을 실제 온디바이스 하드웨어에서 어떻게 실행하느냐'는 커널·컴파일러 레벨의 병목이 레이턴시·전력을 얼마나 좌우하는지를 보여주는 사례다."
    source_url: "https://arxiv.org/abs/2511.11248"
  - title: "양자화 후 처리로 정확도를 더 짜낸다 — ReQuant, 고정 그리드 위에서 이산 가중치 배정을 재조정하는 플러그인형 PTQ 후처리"
    type: "논문"
    summary: "대부분의 PTQ 기법은 라운딩이나 클리핑 규칙을 한 번 정하면 그 결과로 나온 이산 가중치 배정을 그대로 확정하는데, ReQuant는 여기서 한 걸음 더 나아가 이미 양자화가 끝난 모델을 출발점 삼아 같은 고정 그리드 위에서 각 가중치의 이산 배정을 역전파 없이 반복적으로 재검토한다. 재조정은 평균제곱 재구성 오차를 엄격히 줄이는 방향으로만 채택되기 때문에 어떤 PTQ 파이프라인 뒤에도 붙일 수 있는 플러그인형 후처리 단계로 동작한다. Llama-3 8B/70B, Qwen3-14B를 W4A16부터 W2A4까지 다양한 비트 설정으로 실험한 결과, RTN처럼 단순한 초기화 기법일수록, 그리고 비트폭이 낮을수록 개선 폭이 크게 나타났고, 단순 RTN 초기화를 여러 차례 재조정만으로 GPTAQ 수준까지 끌어올린 사례도 보고됐다. 새로운 양자화 알고리즘을 개발하는 대신 '이미 나온 양자화 결과를 같은 그리드 안에서 얼마나 더 정교하게 다듬을 수 있는가'라는 관점을 제시한다는 점에서, PTQ의 원리를 초기화 방식과 사후 정제 방식으로 분리해 이해하는 데 도움이 된다."
    source_url: "https://arxiv.org/abs/2608.07019"
  - title: "2비트로 깎인 정확도, LoRA와 합성 데이터 증류로 되찾다 — Recover-LoRA의 선택적 초저비트 복구 전략"
    type: "논문"
    summary: "LLM을 2비트까지 공격적으로 양자화하면 메모리·처리량 이득은 크지만 정확도 손실도 심각한데, Recover-LoRA는 이 손실을 라벨 데이터 없이 합성 데이터만으로 회복하는 방법을 제시한다. 핵심은 전 레이어를 일괄 2비트로 내리는 대신 MLP의 gate·up 프로젝션만 그룹 크기 32의 INT2로 양자화하고 나머지 선형 레이어는 BF16 고정밀도로 남기는 선택적 혼합정밀도 전략이다. 그 위에 저랭크 어댑터를 얹어 로짓 증류(logit distillation) 방식으로 합성 데이터 1만 개만 가지고 학습시키면, Qwen3-4B 기준 12개 벤치마크 중 9개에서 정확도의 80~95%를 되찾았고, 4비트 베이스에 gate/up만 2비트로 낮춘 W4/W2-GateUp 구성은 균일 W4 대비 처리량(TPS)이 모델과 컨텍스트 길이에 따라 7.5~23.3% 더 높았다. 어떤 레이어를 얼마나 깎을지 선별하는 문제와, 깎인 뒤 정확도를 어떻게 되돌릴지의 문제를 분리해서 다뤘다는 점에서, '균일 저비트'가 아니라 '레이어별 차등 압축 + 경량 복구 학습'이 초저비트 양자화의 실용적 해법이 되고 있음을 보여준다."

  - title: "레이어별로 따로 최적화하지 말고 한꺼번에 봐라 — 프루닝과 혼합정밀도 양자화를 전역 오차 전파 기준으로 공동 최적화하다"
    type: "논문"
    summary: "기존 PTQ는 레이어 단위로 양자화 오차를 최소화할 뿐 그 오차가 뒤쪽 레이어로 어떻게 누적·전파되는지는 반영하지 않고, 프루닝과 양자화도 대개 순서를 정해 따로따로 적용해 왔다. 이 논문은 두 가지를 동시에 겨냥한다. 첫째는 레이어별 오차가 아니라 모델 전체에 걸친 전역 오차 전파를 직접 최소화하는 혼합정밀도 PTQ 전략이고, 둘째는 구조적 프루닝 결정과 혼합정밀도 비트 배분을 하나의 최적화 문제로 묶어 동시에 학습하는 공동 최적화 방식이다. 이는 최근 이 카테고리에서 다룬 '프루닝 후 양자화냐 양자화 후 프루닝이냐'라는 순서 문제와는 다른 축의 질문으로, 순서를 고정하고 그 순서가 맞는지를 따지는 대신 애초에 순서라는 제약 자체를 없애고 두 압축 축을 동시에 탐색하면 전역 오차 관점에서 더 나은 해를 찾을 수 있다는 주장이다. 프루닝·NAS·양자화를 개별 기법으로 비교하는 관점을 넘어, 압축 결정 변수들을 얼마나 결합해서 최적화하느냐 자체가 경량화 파이프라인 설계의 새로운 축이 되고 있음을 보여준다."
    source_url: "https://arxiv.org/abs/2606.07819"
