  - title: "'계획 지향' 관점으로 다시 그린 엔드투엔드 자율주행 아키텍처 지형도"
    type: "논문"
    summary: "엔드투엔드 자율주행은 카메라 입력을 곧바로 제어값으로 매핑하던 초기 회귀 방식에서, 구조화된 중간 표현과 궤적 단위 출력, 더 현실적인 평가 프로토콜을 갖춘 '계획 지향(planning-oriented)' 방식으로 진화해 왔다. 이 서베이는 행동 복제(behavior cloning), 조건부 모방학습, privileged distillation부터 BEV/벡터화 플래닝, 인지-예측-계획 통합 아키텍처, 월드모델 기반 플래너, VLA 계열까지를 하나의 계보로 정리하면서 핵심 쟁점을 '중간 표현을 쓰느냐 마느냐'가 아니라 '그 표현이 학습·지도·평가되어 안전하고 실행 가능하며 경로 준수적인 계획을 실제로 뒷받침하느냐'로 재정의한다. 매일 쏟아지는 개별 모듈 논문들을 모듈형이냐 엔드투엔드냐는 이분법이 아니라 '표현 설계의 성숙도'라는 하나의 축으로 꿰어 볼 수 있게 해준다는 점에서, SW 스택 아키텍처 트렌드를 정리해서 보고 싶은 사람에게 유용한 지도 역할을 한다."
    source_url: "https://arxiv.org/abs/2608.20111"
  - title: "미니어처 애커먼 차량으로 시뮬레이션-실차 격차를 정량적으로 재보는 오픈 플랫폼"
    type: "논문"
    summary: "자율주행 학습 방법론 연구는 대개 대형 실차 데이터셋이나 폐쇄형 사내 시뮬레이터에 의존해 재현이 어렵다는 문제가 있는데, 이 연구는 실제 애커먼 조향 미니어처 차량과 인쇄된 도심 트랙, 데이터 수집·궤적 기록 도구, 그리고 Webots 기반 디지털 트윈을 하나로 묶어 시뮬레이션 기법과 실차 주행 결과를 직접 비교할 수 있는 저비용 오픈 실험대를 제시한다. 카메라 영상과 주행 명령만으로 조향·속도를 출력하는 명령조건부 행동 복제를 기준선으로 삼아, 디지털 트윈에서 만든 합성 주행 데이터를 학습된 sim-to-real 이미지 변환기로 외관 격차를 줄인 뒤 실제 데이터와 섞어 학습했을 때만 네 개 트랙 경로를 모두 폐루프로 완주했다는 결과는, '시뮬레이션 데이터를 얼마나 사실적으로 바꾸느냐'가 합성 데이터 학습 성패를 가른다는 점을 소규모 하드웨어에서 통제된 방식으로 재확인시켜 준다. 대형 연구소가 아니어도 sim-to-real 방법론을 직접 검증해볼 수 있는 재현 가능한 벤치마크를 제공한다는 점에서 방법론 연구자들에게 의미가 크다."
    source_url: "https://arxiv.org/abs/2609.04147"
