    type: "논문"
    summary: "CoT 언어 추론을 곁들인 VLA 자율주행 모델들은 대체로 '설명 가능하니 매 프레임 추론을 생성하는 게 당연히 좋다'는 전제를 깔고 있는데, 이 논문은 실제로 언어가 주행 성능에 유의미한 영향을 주는 구간은 전체 주행 경로 중 극히 일부뿐이며, 나머지 대부분의 프레임에서는 언어 생성이 순수한 연산 낭비라는 사실을 실증적으로 드러낸다. 저자들은 백본을 건드리거나 추가 사람 라벨링 없이, 고정된(frozen) VLA의 hidden state 위에 0.11M 파라미터짜리 아주 가벼운 게이트만 얹어 프레임마다 언어를 생성할지 곧바로 행동을 예측할지를 결정하게 하는 BLUE를 제안한다. DE-Driver 같은 이중 전문가 구조가 '언제 깊이 생각할지'를 큰 모델 구조로 풀었다면, 이 연구는 '애초에 언어 추론이 실제로 기여하는 지점이 얼마나 좁은가'를 먼저 정량적으로 규명하고 그 위에 최소한의 개입으로 답했다는 점에서, reasoning VLA 유행에 대한 절제된 반증 사례로 읽을 가치가 있다."
    source_url: "https://arxiv.org/abs/2606.08684"

    type: "논문"
    summary: "레이더-카메라 BEV 인식 모델은 학습에 쓴 데이터셋과 다른 센서 배치·해상도·환경 조건을 가진 데이터셋에 옮겨 쓰면 성능이 크게 떨어지는데, 이는 단순히 '더 많은 타깃 도메인 데이터로 미세조정하면 되는' 문제가 아니라 입력 관측치와 모델 내부의 융합 표현 자체가 함께 흔들리기 때문이라는 게 이 논문의 출발점이다. 저자들은 타깃 도메인 샘플에 의존하지 않고, 소스 도메인 자체에서 발생하는 시각적 장면 변화를 주파수 영역(frequency domain)에서 정량적으로 특징짓고 이를 이용해 다양한 소스 도메인 뷰를 합성함으로써 모델이 처음부터 더 넓은 변동성에 노출되도록 학습시키는 프레임워크를 제안한다. View-of-Delft와 TJ4DRadSet 간 크로스 데이터셋 검증에서 여러 BEV 퓨전 백본에 일관된 개선을 보였고, 소량의 타깃 도메인 데이터가 있을 때도 효과가 유지된다는 점에서, '센서가 고장 났을 때'가 아니라 '센서 구성 자체가 다를 때'의 강건성이라는 또 다른 축의 문제를 다룬다."
    source_url: "https://arxiv.org/abs/2606.11573"
  - title: "격자를 버리고 가우시안으로 — GaussianFusion이 던지는 BEV 표현 자체에 대한 질문"
    type: "논문"
    summary: "BEVFusion 이후 대부분의 멀티모달 퓨전 인식 모델이 카메라·라이다 특징을 하나의 이산적(discrete) BEV 격자 위에 투영해 합치는 방식을 표준으로 삼아왔지만, 이 논문은 격자라는 표현 자체가 세밀한 디테일 손실을 야기하고 모달리티 간 특징 정렬과 상호작용을 제약하는 근본 원인이라고 지적한다. 해법으로 제안한 GaussianFusion은 BEV 격자 패러다임에서 완전히 벗어나, 연속적인(continuous) 3D 가우시안 공간 위에서 여러 모달리티 특징을 자연스럽게 통합하는 범용 프레임워크로, 전방 투영 기반의 멀티모달 가우시안 초기화 모듈과 어텐션으로 가우시안 속성을 반복 갱신하는 공유 크로스모달 인코더를 결합한다. nuScenes에서 BEVFusion 대비 3D 검출 NDS를 2.6포인트 끌어올리고 3D 시맨틱 오큐판시에서는 가우시안 개수를 30%만 쓰고도 GaussFormer보다 mIoU 1.55포인트 높은 성능과 450% 속도 향상을 동시에 달성했다는 점에서, '퓨전 알고리즘을 어떻게 개선할까'를 넘어 '애초에 어떤 공간 표현 위에서 퓨전할까'라는 더 근본적인 설계 질문을 던진다."
    source_url: "https://arxiv.org/abs/2607.00746"
  - title: "자율주행이 '혼자 잘하는 차'에서 '함께 아는 차들'로 — Shared World Model 서베이"
    type: "개념정리"
    summary: "지금까지의 자율주행 SW 연구는 대부분 한 대의 차량이 자기 센서만으로 인식·예측·판단하는 것을 전제로 해왔는데, 이 서베이는 자율주행이 고립된 차량 지능에서 차량-인프라-다른 교통 참여자가 인식을 공유하고 서로의 의도를 추론하며 행동을 조율하는 멀티에이전트 임베디드 시스템으로 옮겨가고 있다는 문제의식 아래, V2X 통신·협력 인식·에이전트 간 인지·협력 계획·엔드투엔드 협력 주행·클로즈드루프 검증용 시뮬레이션까지 380편 넘는 문헌을 Shared World Model(SWM)이라는 하나의 틀로 정리한다. 서베이가 짚는 핵심은 '교환된 관측치가 어떻게 정렬된 상태(aligned state), 의도를 아는 상호작용(intent-aware interaction), 조율된 하위 행동(coordinated action)으로 이어지는가'라는 조직 원리이며, 동시에 현재 연구 대부분이 시뮬레이션·정제된 벤치마크·오프라인 프로토콜에 머물러 있고 파운데이션 모델 기반 협력에는 실시간 안전성 보장이 아직 없다는 한계를 지적한다. 단일 차량 관점에 머물러 있던 이 카테고리의 그간 흐름에, '여러 에이전트가 세계 모델을 공유한다'는 완전히 다른 축의 설계 문제를 던져주는 자료다."
    source_url: "https://arxiv.org/abs/2606.13840"
  - title: "표현·추론·물리를 분리해 코너 케이스를 합성하다 — CARLA-GS의 모듈형 시뮬레이션 설계"
    type: "논문"
    summary: "자율주행 안전 검증은 결국 발생 빈도가 극히 낮은 코너 케이스에서 갈리는데, 이런 장면을 의도적으로 합성하는 문제는 사실 사실적인 시각 표현, 어떤 상황이 위험한지 판단하는 장면 추론, 그리고 물리적으로 그럴듯한 차량 궤적 생성·제어라는 서로 다른 성격의 하위 문제가 뒤섞인 다중 소스 문제라는 게 이 논문의 출발점이다. CARLA-GS는 이 세 축을 하나의 거대한 생성 모델에 욱여넣는 대신, 실주행 데이터로부터 기하학적 일관성 제약을 더한 편집 가능한 가우시안 장면을 재구성하는 시각 표현 모듈, 위험한 상호작용을 식별하고 의도 수준의 웨이포인트 궤적을 생성하는 멀티에이전트 LLM 추론 모듈, 그리고 PID 제어로 운동학적·동역학적 타당성을 보장하는 CARLA 물리 실행 모듈로 명확히 분리하되 서로 긴밀하게 연동되도록 설계했다. AutoScale이 실-합성 데이터의 '배합 비율'을 최적화 문제로 다뤘다면, 이 논문은 애초에 코너 케이스라는 합성 데이터 자체를 '표현/추론/물리'라는 서로 다른 역할로 모듈화해 만들어야 한다는 시뮬레이션 파이프라인 설계 철학을 제시한다는 점에서 결이 다르다."
