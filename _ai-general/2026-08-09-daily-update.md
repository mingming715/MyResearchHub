  - title: "에이전트 워크로드는 GPU가 아니라 CPU-GPU 경계에서 병목된다 — 마이크로소프트 애저 실증 연구"
    type: "논문"
    summary: "에이전트가 스스로 계획하고 도구를 호출하며 여러 모델 추론을 오케스트레이션하는 '에이전틱 워크로드'는 기존 LLM 서빙과 근본적으로 다른 자원 사용 패턴을 보인다는 사실을, 마이크로소프트 애저의 실제 프로덕션 트래픽과 오픈소스 프레임워크 제어 실험을 통해 정량적으로 규명한 연구다. 오케스트레이션과 도구 호출이 호스트(CPU) 측에서 실행되면서 CPU가 임계 경로(critical path)에 올라서게 되고, 전체 요청 중 27% 이상에서 도구 실행 시간이 LLM 추론 시간과 맞먹거나 이를 초과했다. 작업 실행 구조(버스티한 부하 스파이크)와 모델 구성(다양한 태스크·도구 혼합)이 GPU 사용의 불균일성을 키워, GPU 전용으로 설계된 균질한 서버 아키텍처가 에이전틱 워크로드에는 근본적으로 맞지 않는다는 점을 보였다. 저자들은 유휴 CPU 코어를 동적으로 회수하고 GPU 메모리를 오버서브스크립션하는 프로토타입 'Agora'로 이 불일치를 완화할 수 있음을 보여, 도구 사용·멀티에이전트 오케스트레이션 같은 에이전트 설계 패턴이 이제 소프트웨어뿐 아니라 데이터센터 하드웨어 설계에도 실질적 영향을 미치는 단계에 이르렀음을 보여준다."

  - title: "AI가 처음부터 설계한 바이러스 게놈이 실제로 작동했다 — 생물보안 거버넌스 공백 경고"
    type: "뉴스"
    summary: "스탠퍼드대 Brian Hie 연구팀과 Arc Institute가 유전체 파운데이션 모델 Evo 2를 이용해 자연 박테리오파지 ΦX174의 구조를 기반으로 302개의 후보 바이러스 게놈을 생성했고, 그중 16개가 실제로 조립되어 대장균을 감염·용균시키는 기능성 바이러스로 확인됐다고 Science에 발표했다. 이는 생성형 AI가 기존 서열을 분석·변형하는 수준을 넘어 자연에 존재한 적 없는 완전한 기능성 게놈을 처음부터(from scratch) 설계해 살아있는 세포 안에서 작동시킨 최초 사례로, 항생제 내성균 대응(파지 치료) 같은 응용 가능성과 함께 이중용도(dual-use) 위험을 동시에 드러낸다. Science에 동반 게재된 존스홉킨스 생물보안 전문가들의 논평은, DNA 합성 주문을 걸러내는 현행 스크리닝 시스템이 '자연에 존재했던 서열'을 기준으로 설계되어 있어 AI가 새로 창작한 서열은 애초에 탐지 대상이 아니며, 이를 규율할 거버넌스 체계가 아직 존재하지 않는다고 지적했다. 이는 정렬·안전성 논의가 텍스트 기반 모델의 탈옥·해킹을 넘어 생물학 파운데이션 모델의 위험 표면으로까지 확장되고 있음을 보여주는 사례다."
    source_url: "https://www.science.org/doi/10.1126/science.aej8512"
