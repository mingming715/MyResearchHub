    type: "논문"
    summary: "1B~2B급 온디바이스 비전-언어모델(VLM)을 2비트까지 낮추면 기존 PTQ/QAT는 정확도가 크게 떨어지는데, AAAI 2026에 채택된 SPEED-Q는 비전 인코더와 언어모델이 양자화에 반응하는 민감도가 다르다는 점에 착안해 두 모듈을 단계적으로 따로 처리하고, 풀프리시전 모델을 교사로 쓰는 증류로 저비트 학습을 안정화한다. 2비트에서 기존 기법보다 최대 6배 높은 정확도를, 4비트에서는 BF16 대비 약 3%p 손실까지 좁혔다고 보고하며, InternVL3-1B를 400MB 미만 메모리로 구동하면서도 더 큰 경쟁 모델과 맞먹는 성능을 낸다는 점에서 '양자화 따로, 증류 따로'가 아니라 결합 설계가 중요하다는 걸 보여주는 사례다."
    source_url: "https://arxiv.org/abs/2511.08914"
  - title: "GELU 때문에 반쪽만 정수였다 — IPTQ-ViT가 비전 트랜스포머를 완전 정수 연산으로 만드는 법"
    type: "논문"
    summary: "기존 PTQ 기법들은 LayerNorm·Softmax는 정수로 바꿔도 GELU는 부동소수점으로 남겨둬 '완전 정수 전용(integer-only)' 비전 트랜스포머를 만들지 못했는데, WACV 2026에 채택된 IPTQ-ViT는 재학습 없이 이 비선형 연산들을 정수 근사로 바꾸는 PTQ 프레임워크를 제시한다. W8A8/W4A8 설정에서 '일부만 정수화'하던 기존 PTQ 기법들을 넘어서는 정확도(이미지 분류 top-1 평균 1.78%p, 최대 6.44%p 개선, 객체탐지 mAP 1.0 개선)를 내면서도 정수 전용 QAT 기법과 맞먹는 지연시간을 보여, 재학습 비용 없이도 에지 가속기가 요구하는 '끝까지 정수'라는 제약을 만족시킬 수 있음을 보였다."
    source_url: "https://arxiv.org/abs/2511.15369"
  - title: "LoRA 하나 바꿀 때마다 모델 전체를 다시 양자화해야 했다 — 퀄컴 NPU 폰에서 재양자화 없이 어댑터만 바꿔 끼우는 법"
    type: "논문"
    summary: "양자화된 베이스 모델에 LoRA 어댑터를 여러 개 얹어 쓰는 멀티-LoRA 구조는, 어댑터마다 활성값 분포가 달라 베이스 모델의 양자화 파라미터(스케일·제로포인트)까지 함께 다시 계산해야 하는 문제가 있었다. ACL 2026 Findings 논문은 양자화된 LLaMA 기반 모델에 9개 언어·8개 애플리케이션용 LoRA를 붙이고 삼성 갤럭시 S24/S25의 퀄컴 NPU(SM8650/SM8750)에서 실제로 구동해, 어댑터를 교체해도 재컴파일·재양자화 없이 작업을 전환할 수 있음을 보였다. 같은 아이디어가 양자화된 디퓨전 모델에 적용된 QUAD(arXiv:2603.29535) 연구와 함께, '하나의 모델을 양자화해서 여러 용도로 돌려쓰기'가 온디바이스 배포의 실제 제약으로 떠오르고 있음을 보여준다."
    source_url: "https://arxiv.org/abs/2604.18655"
