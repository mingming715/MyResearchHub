    summary: "PTQ 기법 대부분은 추론 중 활성화 분포에 맞춰 스케일을 다시 계산하는 동적 양자화에 의존하는데, 이는 그 구조를 하드웨어로 고정해버린 모바일 NPU에서는 애초에 지원되지 않는다. Quant.npu는 학습 가능한 양자화 파라미터와 회전행렬(rotation matrix)을 결합해 런타임 재계산 없이도 저비트 가중치·활성화 양자화를 '완전히 정적으로' 만드는 두 단계 파이프라인을 제안하고, 민감도 기반 혼합정밀도까지 더해 퀄컴 SM8650 위에서 1~3B급 모델을 최대 15.1% 더 빠르게 돌렸다. 양자화 알고리즘 자체의 정확도만 보던 기존 논의와 달리, '그 알고리즘이 실제 NPU 명령어셋 위에서 돌아갈 수 있는가'라는 배포 단계의 제약을 정면으로 다룬다는 점에서 온디바이스 추론 최적화를 공부하는 사람에게 중요한 사례다."

    type: "개념정리"
