    type: "논문"
    summary: "지금까지 이 분야 업데이트는 양자화 기법 하나에 집중된 논문이 많았는데, UniComp는 거꾸로 프루닝·양자화·지식 증류 세 가지를 40개 이상의 벤치마크에서 동일한 기준으로 비교한 평가 프레임워크다. 결론은 '양자화가 성능 유지와 효율성 사이에서 가장 균형 잡힌 선택'이고, 증류는 런타임 속도 개선이 가장 크지만 그만큼 학습 비용이 크다는 것 — 즉 경량화 기법마다 치르는 대가의 종류가 다르다는 점을 수치로 보여준다. 또 하나 흥미로운 발견은 압축이 모든 능력을 똑같이 깎아내지 않는다는 것으로, 지식 암기(knowledge recall) 과제는 압축 후에도 비교적 잘 버티는 반면 추론·다국어·지시 따르기 성능은 눈에 띄게 떨어진다. 저자들은 프루닝된 모델에 과제별 캘리브레이션을 적용하면 손실된 추론 성능을 최대 50%까지 회복할 수 있다고도 보고하는데, 이는 '어떤 기법을 쓰느냐'보다 '무엇을 지키고 싶은가'에 따라 경량화 전략을 다르게 짜야 한다는 실전적 시사점을 준다."

  - title: "양자화만 했더니 상태공간모델(SSM)이 반토막 — 범인은 state matrix A였다"
    type: "논문"
    summary: "이 논문은 지금까지 다룬 LLM·ViT·오디오·포인트클라우드와는 다른 도메인인 상태공간모델(State-Space Model, S4D 계열)의 양자화 민감도를 다룬다. 트랜스포머에서는 PTQ(학습 후 양자화)가 대체로 무난하게 통하지만, 순환 구조를 가진 SSM에서는 내부 상태를 갱신하는 state matrix A와 내부 상태 x가 양자화에 특히 취약해서, 8비트 PTQ만 적용했을 때 Sequential MNIST 정확도가 40%까지 추락한다. QAT(양자화 인식 학습)를 적용하면 이 정확도가 96%까지 회복되는데, 이는 같은 비트 수라도 '언제 양자화 오차를 학습 과정에 반영하느냐'가 아키텍처에 따라 결정적으로 달라질 수 있음을 보여주는 사례다. 저자들은 더 나아가 모델 구성 요소별로 정밀도를 다르게 주는 이종 정밀도(heterogeneous precision) 방식을 제안해 정확도 손실 없이 메모리 사용량을 6배 줄였는데, 이는 순환·시퀀셜 구조를 가진 경량 모델을 엣지에 올릴 때 '민감한 부분만 선별적으로 보호'하는 접근이 왜 필요한지를 잘 보여주는 공부 자료다."
    source_url: "https://arxiv.org/abs/2506.12480"
