  - title: "가지치기 비율도 비트폭도, 이제 AI 에이전트가 정한다"
    type: "논문"
    summary: "APQF는 구조적 가지치기(pruning)와 혼합정밀도 양자화(mixed-precision QAT)를 사람이 손으로 튜닝하던 방식 대신, 프로파일링 에이전트가 레이어별 연산 비용과 민감도를 측정하고 이를 근거로 가지치기 에이전트와 양자화 에이전트가 각각 레이어별 프루닝 비율과 비트폭을 결정하며 파인튜닝 에이전트가 정확도 손실을 회복하는 완전 자동화 파이프라인을 제시한다. ResNet부터 ViT, DeiT, Swin까지 CNN과 비전 트랜스포머 전반에서 검증했고, ImageNet 기준 비트연산량을 원본의 5.6~7.7%(13~18배 감소)까지 줄이면서도 정확도를 거의 유지했으며, 제한된 데이터 예산(20만 장) 상황에서는 기존 결합형 프루닝 기법보다 Top-1 정확도가 17%p가량 높았다. 특정 레이어·아키텍처마다 최적 압축 설정이 달라 전문가의 수작업 튜닝에 의존해온 압축 파이프라인 설계 자체를 LLM 에이전트에게 위임하려는 시도라는 점에서, '어떤 기법이 더 나은가'를 넘어 '압축 결정을 누가/어떻게 내리는가'라는 새로운 축을 보여준다."
    source_url: "https://arxiv.org/abs/2608.05499"
  - title: "정확도는 그대로인데 모델은 딴 사람이 됐다 - 양자화의 '동등성 착시'"
    type: "논문"
    summary: "PTQ 평가는 거의 전적으로 정확도(accuracy)나 퍼플렉시티 같은 집계 지표에 의존해왔는데, 이 논문은 그런 지표들이 양자화가 실제로 일으키는 행동 변화를 전혀 포착하지 못한다는 것을 보여준다. 저자들은 원본 모델과 양자화 모델이 '같은 문제를 맞혔는지'를 절대 정확도와 무관하게 비교하는 새 지표(correctness agreement)를 도입했는데, 8비트에서 2비트까지 다양한 양자화 스킴에서 태스크 성능 지표상으로는 멀쩡해 보여도 중간 수준 양자화만으로 이미 상당한 행동 발산이 나타났다. 또한 어텐션 가중치를 구조적 연산자로 분석해 레이어별 왜곡을 통계적으로 정량화한 결과, 낮은 비트폭에서 비선형적 붕괴 지점이 존재하며 특히 query·key 프로젝션이 value·output 프로젝션보다 훨씬 더 취약하다는 것을 밝혔다. '정확도가 유지되면 양자화는 안전하다'는 업계의 암묵적 가정 자체를 정면으로 반박하는 논문이라 평가 방법론 차원에서 파급력이 크다."
    source_url: "https://arxiv.org/abs/2607.08734"
  - title: "가지치기 먼저 vs 양자화 먼저 - 압축 '순서'가 정확도를 좌우한다"
    type: "논문"
    summary: "가지치기와 양자화를 함께 적용하는 파이프라인에서 정작 거의 다뤄지지 않았던 변수가 '어떤 순서로 적용하느냐'인데, 이 논문은 '더 약한 교란을 먼저, 더 강한 교란을 나중에 적용해야 한다(Progressive Intensity Hypothesis)'는 가설을 이론적으로 증명하고 언어모델과 비전모델 양쪽에서 실험으로 검증했다. 두 압축 기법 사이의 성능 격차가 클수록 특정 순서(약한 쪽 먼저)의 이점이 커진다는 이론적 보장을 제시했고, 이 원리가 다단계 압축이나 혼합정밀도 양자화처럼 더 넓은 설정에도 일반화됨을 보였다. 실무에서 '가지치기 후 양자화'와 '양자화 후 가지치기' 중 관행적으로 하나를 택해온 경우가 많았는데, 그 선택 자체를 최적화 대상으로 격상시켜 압축 파이프라인 설계에 실질적인 체크리스트를 제공한다는 점이 흥미롭다."
    source_url: "https://arxiv.org/abs/2603.18426"
  - title: "INT4 말고 FP4 - 엔비디아 NVFP4 포맷을 엣지 저전력 환경에서 뜯어보다"
    type: "논문"
    summary: "그동안 엣지 양자화 논의는 대부분 INT4/INT8 정수 포맷에 집중돼 있었는데, 이 논문은 4비트 FP4 값과 FP8 블록 스케일, FP32 텐서 스케일을 결합한 엔비디아의 마이크로스케일링 포맷 NVFP4를 저전력 엣지 신경망에 적용했을 때의 정확도·저장공간 트레이드오프를 블록 크기, 가중치 정밀도, 재학습 여부별로 체계적으로 분해했다. 6개 엣지 효율 모델에 대한 블록 크기 실험에서 블록크기 16이 입력당 약 4.5비트로 실용적인 정확도/저장 균형점을 제공했고, FP8·FP16 가중치는 같은 NVFP4 활성화 경로에서 FP4 가중치 대비 이득이 크지 않아 정확도를 좌우하는 것은 결국 활성화 양자화와 스케일링임을 보였다. 압축률·에너지가 최우선이면 FP4 가중치로 충분하지만 민감한 레이어에는 FP8/FP16이 필요하다는 실용적 가이드를 제시해, 정수 양자화 일변도였던 엣지 논의에 마이크로스케일링 포맷이라는 새로운 축을 더한다."
    source_url: "https://arxiv.org/abs/2606.06527"
