  - title: "World Engine: 강화학습 기반 자율주행 사후학습(post-training) 프레임워크"
    type: "논문"
    summary: "OpenDriveLab이 제안한 World Engine은 실주행 로그를 고품질 상호작용 시뮬레이션으로 재구성한 뒤, Behavior World Model(BWM)로 희귀한 안전 위협 시나리오를 조밀한 학습 분포로 확장해 강화학습 기반 사후학습에 활용하는 프레임워크다. 핵심 문제의식은 실제 도로에서 위험 상황을 직접 겪지 않고도 정책을 안전 제약에 맞게 정렬시키는 것으로, LLM의 RLHF 사후학습 개념을 자율주행 세계모델에 적용한 사례다. nuPlan 기반 벤치마크에서 사전학습 데이터를 10배 늘리는 것보다 더 큰 성능 향상을 보였고, 8만 시간 이상의 실주행 로그로 학습된 양산 ADAS 플랫폼에 실제로 배포해 시뮬레이션 충돌률을 45.5% 낮추고 200km 실도로 테스트에서 무개입 주행을 달성했다는 점에서, 시뮬레이션 기반 방법론이 실차 검증까지 이어진 드문 사례다."
    source_url: "https://arxiv.org/abs/2606.19836"
  - title: "CoWorld-VLA: 멀티 전문가 잠재 사고사슬로 세계 표현을 계획에 직접 연결하는 VLA"
    type: "논문"
    summary: "기존 VLA(Vision-Language-Action) 모델은 텍스트 기반 Chain-of-Thought가 연속적인 시공간 구조를 보존하지 못하거나, 잠재적 세계모델 표현이 행동 생성의 직접적 조건으로 쓰이기 어렵다는 두 가지 한계를 안고 있었다. CoWorld-VLA는 의미적 상호작용·3D 기하·동적 변화·자아 궤적을 각각 담당하는 '전문가 토큰'들로 VLM의 잠재 공간 안에 멀티 전문가 잠재 CoT를 구성해, 플래너가 직접 참조할 수 있는 조건 신호로 제공한다. 이는 VLA 아키텍처 설계에서 '추론 과정을 어떤 형태로 표현해야 실제 계획에 쓸모 있는가'라는 근본적 질문에 구조적 답을 제시한 것으로, 자연어 CoT와 순수 잠재 CoT 사이의 절충안을 모색한 접근이다."
    source_url: "https://arxiv.org/abs/2605.10426"
  - title: "AutoDrive-P³: 지각-예측-계획을 하나의 사고사슬로 묶은 강화학습 프레임워크 (ICLR 2026)"
    type: "논문"
    summary: "VLM 기반 E2E 자율주행 모델들은 CoT 없이 곧바로 계획 결과만 내놓아 지각·예측 단계를 생략하거나, 각 태스크별 CoT는 만들지만 모듈이 서로 분절되어 작동한다는 두 갈래 문제를 안고 있다. AutoDrive-P³는 지각→예측→계획이 순차적으로 서로를 조건화하며 추론하도록 만든 P³-CoT 데이터셋과, 세 태스크에 걸쳐 점진적 감독 신호를 제공하는 계층적 강화학습 알고리즘 P³-GRPO를 제안하고, 상황에 따라 '상세 사고'와 '빠른 사고' 두 모드를 전환하는 구조를 갖췄다. ICLR 2026에 채택된 이 연구는 모듈형이냐 E2E냐라는 이분법을 넘어, 사고사슬 내부에서 모듈 간 인과적 연결을 명시적으로 강제하는 것이 왜 필요한지를 보여주는 아키텍처 철학 논쟁의 실질적 해법이라는 점에서 주목할 만하다."
    source_url: "https://arxiv.org/abs/2603.28116"
  - title: "PRIX: BEV·라이다 없이 원시 픽셀만으로 계획하는 경량 E2E 모델 (RA-L·IROS 2026)"
    type: "논문"
    summary: "대다수 최신 E2E 자율주행 모델이 의존하는 BEV(Bird's-Eye-View) 중간 표현과 라이다 센서가 계산 비용과 하드웨어 비용을 크게 늘린다는 문제의식에서, PRIX는 카메라 영상만 입력받아 원시 픽셀에서 곧바로 안전 궤적을 생성하는 구조를 제안한다. 핵심 모듈인 Context-aware Recalibration Transformer(CaRT)가 다중 레벨 시각 특징을 재보정해 별도의 BEV 투영 없이도 공간 정보를 활용하며, 3700만 파라미터·초당 57프레임의 경량 구성으로 NavSim·nuScenes 벤치마크에서 훨씬 큰 멀티모달 확산 플래너와 동등한 성능을 냈다. RA-L 게재 및 IROS 2026 발표가 확정된 이 연구는 'BEV 중간표현이 정말 필수인가'라는 질문에 정면으로 반박하며, 저비용 카메라 전용 구성이라는 대안적 설계 축을 제시한다는 점에서 BEV 퓨전 중심의 최근 트렌드와 대비된다."
    source_url: "https://arxiv.org/abs/2507.17596"
