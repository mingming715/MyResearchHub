  - title: "레이어를 순서대로 깎지 않는다 — SliderQuant이 '순차적 PTQ'라는 전제를 비튼 방법"
    type: "논문"
    summary: "지금까지 LLM용 PTQ(post-training quantization)는 레이어를 앞에서부터 순서대로 하나씩 양자화하면서, 앞 레이어의 양자화 오차가 뒤 레이어 보정에 그대로 누적되는 구조를 당연하게 받아들였다. ICLR 2026에 채택된 SliderQuant은 이 순차 구조 자체를 문제로 보고, 적은 수의 학습 가능한 파라미터만으로 레이어 경계를 '슬라이딩'시켜 오차가 한쪽 방향으로만 누적되지 않도록 재구성한 PTQ 프레임워크를 제안한다. 양자화 기법 자체의 수치 트릭보다 '어떤 순서로, 어떤 단위로 오차를 나눠서 흡수할 것인가'라는 설계 전제를 다시 묻는다는 점에서, PTQ의 원리를 공부하는 사람이 눈여겨볼 만한 변형이다."
    source_url: "https://arxiv.org/abs/2603.25284"
  - title: "캘리브레이션에 진짜 이미지가 없어도 된다 — ViT를 통째로 묶어 양자화하는 PTQ"
    type: "논문"
    summary: "비전 트랜스포머(ViT) PTQ는 보통 각 블록을 따로따로 보정하고, 보정에 쓸 실제 이미지 데이터셋이 필요하다는 두 가지 전제를 깔고 있었다. 이 논문은 학습된 프롬프트로 데이터를 직접 생성해 캘리브레이션에 쓰고, 트랜스포머 블록 전체를 레이블 없이 공동 최적화하는 PTQ 파이프라인을 제안한다. ImageNet에서 4비트 가중치/4비트 활성값(W4A4)은 물론 3비트(W3A3)까지도 쓸 만한 정확도를 유지했고, ViT·DeiT·Swin-T를 삼진(ternary) 가중치(W1.58A8)까지 내리면서도 합리적인 정확도를 지킨 첫 PTQ 결과라고 주장한다. 그동안 다뤘던 LLM 중심 PTQ 변형들과 달리, '실데이터 없이도 양자화 보정이 가능한가'라는 비전 도메인 특유의 질문에 답을 내놓은 사례다."
    source_url: "https://arxiv.org/abs/2602.18861"
