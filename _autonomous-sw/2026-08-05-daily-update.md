    type: "논문"
    summary: "차량-차량/차량-인프라 협력 인지(V2X cooperative perception)는 서로의 센서 특징을 무선으로 공유해 인지 범위를 넓히지만, 통신 대역폭이 제한적이라 매 순간 모든 특징을 전송하는 방식은 실용적이지 않다는 문제에서 출발한다. CooperTrim은 정적인 배경 정보는 반복 전송할 필요가 없다는 발상 아래, conformal 시간적 불확실성 지표로 환경이 실제로 얼마나 변했는지를 측정해 역학 정보를 담은 특징만 데이터 기반으로 선별 전송하는 프레임워크를 제안한다. 여러 오픈소스 협력 분할(segmentation) 모델 실험에서 대역폭을 최대 80.28% 절감하면서도 정확도를 유지했고, 다른 선택 전략 대비 최대 72% 적은 대역폭으로 IoU를 45.54%까지 끌어올렸다. ICLR 2026 채택 논문으로, 협력 인지 연구의 축이 '무엇을 인지하느냐'에서 '무엇을 공유할 가치가 있느냐'로 옮겨가고 있음을 보여준다."

  - title: "자율주행 월드모델은 왜 항상 차량 시점이었나 - 인프라 중심 월드모델이라는 대안"
    type: "논문"
    summary: "Waymo World Model, NVIDIA Cosmos를 비롯해 지금까지의 자율주행 월드모델은 예외 없이 자기차량(ego-vehicle) 시점에서 다음 장면을 예측하도록 설계됐는데, 이 논문은 고정 노변 센서가 가진 조감(bird's-eye)·다중 센서·지속 관측이라는 근본적으로 다른 시공간적 특성이 지금까지 전혀 활용되지 않았다고 지적한다. 고정 인프라 센서는 특정 지점에서 장기간 축적된 희귀 위험 상황 분포('시간적 깊이')를 잘 포착하는 반면, 차량 센서는 넓은 도로망을 오가며 다양한 장면('공간적 폭')을 샘플링한다는 상호보완성이 핵심 논지다. 저자들은 (1) 불확실성 전파를 포함한 생성적 장면 이해, (2) 물리 기반 예측 동역학과 다중 에이전트 반사실적 추론, (3) 잠재공간 정렬을 통한 V2X 협력 월드모델이라는 3단계 연구 비전을 제시한다. 인지 모델의 정확도가 아니라 월드모델의 '관측 시점' 자체를 설계 변수로 다룬다는 점에서, 자기차량 시점에 갇혀 있던 월드모델 연구에 새로운 축을 제안하는 포지션 논문이다."

  - title: "합성 데이터는 많을수록 좋다는 가정을 깨다 - 폐루프 데이터 믹스처 최적화 AutoScale"
    type: "논문"
    summary: "End-to-end 자율주행 학습이 확산되며 실측 데이터의 주석 비용과 장면 편향 문제를 보완하기 위해 무한에 가까운 합성 데이터를 함께 쓰는 real-synthetic co-training이 주목받지만, 이 논문은 합성 데이터를 무작정 많이 섞으면 오히려 분포가 어긋나 성능이 떨어질 수 있다는 실무적 난점을 짚는다. AutoScale은 데이터 믹스처 구성을 '장면 표현 → 믹스처 최적화/검색 → 학습 → 폐루프 평가'가 반복되는 동적 최적화 과정으로 재정의하고, Graph 정규화 오토인코더로 장면을 표현한 뒤 클러스터별 중요도를 그래디언트 상승으로 추정해 가치 높은 샘플만 검색해 재학습에 투입한다. NavSim 실험에서 단순 co-training이나 교차 도메인 베이스라인 대비 더 적은 합성 샘플로도 더 나은 성능을 냈다. '얼마나 많은 합성 데이터를 쓰느냐'가 아니라 '어떤 합성 데이터를 어떤 비율로 쓰느냐'를 자동화했다는 점에서, 시뮬레이션 기반 학습 방법론의 무게중심이 데이터 생성에서 데이터 큐레이션 단계로 옮겨가고 있음을 보여준다."
    source_url: "https://arxiv.org/abs/2605.21372"
