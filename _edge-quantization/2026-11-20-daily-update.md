  - title: "양자화보다 먼저 '메모리 대역폭'이 병목이다 — 구글 LiteRT-LM이 온디바이스 디코딩을 재설계한 방법"
    type: "뉴스"
    summary: "구글이 온디바이스 LLM 런타임 LiteRT-LM의 성능 분석을 공개했다. 핵심 주장은 디코딩 단계가 연산량이 아니라 '토큰마다 수십억 파라미터를 옮기는' 메모리 대역폭에 의해 병목이 걸린다는 것으로, 이를 풀기 위해 보조 드래프트 모델(MTP)과 메인 모델을 같은 하드웨어(같은 IP 블록)에서 실행해 데이터 이동 자체를 줄이는 방향을 택했다. 실측 결과로 아이폰17 프로에서 25억 파라미터급 Gemma 4 E2B(디스크 상 약 2.58GB)를 CPU 기준 607MB 메모리로 돌렸고, 라즈베리파이5 CPU 환경에서도 피크 메모리 1.4GB대로 구동되는 벤치마크를 라즈베리파이 재단이 별도로 검증해 공개했다. 양자화 비트 수를 낮추는 접근과는 별개로, 가중치 캐싱·추측 디코딩(최대 2.2배 가속)·데이터 지역성 같은 '시스템 엔지니어링' 축에서 온디바이스 추론 효율을 어디까지 끌어올릴 수 있는지 보여주는 사례라서, 양자화 연구와 상호보완적으로 봐야 할 지점이다."

  - title: "가지치기와 미세조정을 따로 생각하지 않는다 — NIRVANA가 뉴럴 탄젠트 커널로 '어디를 잘라야 다시 학습이 잘 되는지'부터 정한 이유"
    type: "논문"
    summary: "기존 구조적 가지치기(structured pruning)는 뉴런·어텐션 헤드를 먼저 쳐낸 뒤 후속 미세조정으로 정확도를 복구하는 2단계 방식이 많았는데, 이 복구 과정에서 성능 손실이 크다는 게 고질적 문제였다. NIRVANA(COLM 2026)는 가지치기 결정을 '모델이 미세조정 과정에서 실제로 어떻게 학습하는지'를 설명하는 뉴럴 탄젠트 커널(NTK) 관점과 직접 결합해, 레이어·모듈(어텐션 vs MLP)별로 희소성을 적응적으로 배분한다. Llama3·Qwen·T5 계열에서 검증했고 표준 미세조정 파이프라인에 그대로 끼워 넣을 수 있다고 주장한다. 양자화 일변도였던 최근 경량화 흐름에서, '가지치기 후 복구'라는 오래된 트레이드오프 자체를 이론적으로 다시 짠 시도라는 점에서 가지치기 연구자들에게 참고가 될 만하다."
    source_url: "https://arxiv.org/abs/2509.14230"
