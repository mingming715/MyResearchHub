    type: "뉴스"
    summary: "NVIDIA가 2026년 8월 상용 라이선스(Linux Foundation OpenMDW-1.1)로 공개한 Alpamayo 2 Super는 32B Cosmos 3 Super Reasoner 비전-언어 백본에 2.3B 디퓨전 액션 디코더를 붙이고 RL로 후처리 학습한 340억 파라미터 추론형 VLA 모델이다. 서라운드뷰 카메라 최대 7대를 입력받아 6.4초 앞을 내다보는 64개 웨이포인트 궤적을 내놓으면서, 동시에 왜 그 경로를 택했는지 설명하는 CoC(Chain-of-Causation) 추론 트레이스, yield·차선변경 같은 메타액션, 2D 그라운딩 VQA까지 한 모델에서 함께 출력한다. 흥미로운 점은 NVIDIA가 이를 차량에 바로 올리는 프로덕션 스택이 아니라, 완성차·공급업체가 파인튜닝·증류해 자사 스택 백본으로 삼도록 설계한 '교사 모델'로 포지셔닝했다는 것이다 — 대규모 추론 데이터와 시뮬레이션(AlpaSim)을 오픈 생태계로 함께 풀어 규모의 경제를 만들고, LingoQA 벤치마크에서 Qwen2.5-VL-72B와 Gemini 2.5 Pro를 앞서는 성능으로 사실상 '추론형 주행 VLA'의 업계 표준 자리를 선점하려는 전략으로 읽힌다."

  - title: "SV-WAM — 추론 시엔 미래 영상을 만들지 않고, 학습 때만 '상상'하게 만드는 서라운드뷰 월드-액션 모델"
    type: "논문"
    summary: "최근 월드모델 기반 end-to-end 주행 모델들은 추론 단계에서 미래 영상을 직접 생성하는 방식의 연산 비용이 커서, 실배포 가능한 모델 대부분이 카메라를 전방 1대로 줄여왔다. 문제는 차선변경·합류·회전처럼 안전이 걸린 기동일수록 바로 그 서라운드 시야가 필요하다는 것이다. SV-WAM은 6개 카메라 전체 관측을 유지하면서도 효율적 추론을 하기 위해, 액션 토큰이 미래 영상 토큰을 어텐션으로 들여다보지 못하게 막는 'action-centered causal mask'를 도입한다. 즉 학습 시엔 액션과 미래 영상을 하나의 생성 모델에서 함께 디노이징하며 미래 예측을 액션 학습의 dense supervision으로 쓰고, 추론 시엔 미래 영상 생성 자체를 꺼버려 6-카메라 서라운드 인지는 유지한 채 연산 비용만 제거한다. 여기에 주행가능영역 준수 정규화를 더해, 복잡한 기동에서 예측 궤적이 실제 경로에 더 가깝고 주행가능영역을 벗어나지 않는다는 결과를 보였다 — '생성은 학습용, 인지는 추론용'으로 역할을 분리한 설계다."
    source_url: "https://arxiv.org/abs/2609.03602"
  - title: "Dream4Drive — 월드모델의 '생성 품질'이 아니라 '이걸로 학습한 인식 모델이 실제로 좋아지는가'로 평가축을 되묻다"
    type: "논문"
    summary: "최근 주행 월드모델 연구는 대부분 생성된 영상이 얼마나 사실적이고 조종 가능한지(FID, 컨트롤 정확도 등)만 평가해왔다. ICLR 2026에 게재된 이 논문은 정작 그 영상이 다운스트림 인식 모델 학습에 실제로 도움이 되는지는 아무도 제대로 측정하지 않았다고 지적하며, 월드모델을 '인식 태스크용 합성 데이터 생성기'로 재정의한다. 제안 프레임워크 Dream4Drive는 입력 영상을 여러 개의 3D-aware guidance map으로 분해한 뒤, 자체 구축한 대규모 3D 에셋 데이터셋 DriveObj3D의 오브젝트들을 그 가이던스맵 위에 렌더링하고, 이를 다시 월드모델로 파인튜닝해 멀티뷰의 사실적인 영상으로 바꾼다. 기존의 레이아웃 의존적 생성 방식이 기하학적 다양성이 낮아 롱테일 코너 케이스를 잘 만들지 못한다는 한계를, 3D 에셋을 장면에 직접 삽입하는 방식으로 우회한 것이다. 결과적으로 코너 케이스 인식 성능을 유의미하게 끌어올렸다는 점에서, '생성이 예쁜가'가 아니라 '생성이 모델을 실제로 개선하는가'로 시뮬레이션 데이터 연구의 기준을 옮기려는 시도다."
    source_url: "https://arxiv.org/abs/2510.19195"
  - title: "Crisp-Drive — 월드모델 기반 강화학습에서 '상상'이 길어질수록 무너지는 문제를 게이트 크로스어텐션으로 붙잡다"
    type: "논문"
    summary: "월드모델 기반 RL은 실차 주행 대신 학습된 월드모델 안에서 상상 롤아웃(imagined rollout)을 돌려 end-to-end 주행 정책의 학습 효율을 높이는 접근인데, 하얼빈공대·상하이 Utopilot 연구진은 이 방식이 세 가지 구조적 약점을 갖는다고 지적한다: 롤아웃이 길어질수록 시간적 일관성이 깨지고, 자아차량-주변환경 상호작용을 제대로 모델링하지 못하며, 공격적·보수적 등 다양한 주행 스타일에 적응하지 못한다는 것이다. Crisp-Drive는 과거 latent state를 게이트 크로스어텐션으로 현재 예측에 결합하는 시간적 일관성 정규화를 통해 오차 누적을 줄여 롱호라이즌 상상 롤아웃을 안정화하고, 여기에 상호작용 인지 상태 분해와 멀티스타일 정책 최적화를 더해 하나의 월드모델이 여러 주행 성향의 정책 학습을 동시에 지원하도록 설계했다. 월드모델을 '한 번 학습해서 계속 상상만 시키는 블랙박스'가 아니라 상상이 길어져도 무너지지 않게 구조적으로 붙잡아야 하는 대상으로 다룬다는 점에서, 최근 월드모델-RL 결합 흐름의 안정성 문제를 정면으로 겨냥한 논문이다."
    source_url: "https://arxiv.org/abs/2609.03225"
