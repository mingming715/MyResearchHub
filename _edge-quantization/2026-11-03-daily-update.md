  - title: "같은 4비트인데 왜 정확도가 다르다 — NVFP4·MXFP4 마이크로스케일링 포맷의 숨은 차이"
    type: "논문"
    summary: "FP4급 양자화를 하드웨어에서 네이티브로 지원하는 두 경쟁 포맷인 NVIDIA의 NVFP4와 업계 공동 표준인 MXFP4는 둘 다 '마이크로스케일링'(작은 블록 단위로 스케일 팩터를 따로 둠) 방식을 쓰지만 실제 정확도는 꽤 다르다. ICLR 2026에 실린 이 논문(GPTQ 저자들이 포함된 Alistarh 랩 작업)은 그 이유를 NVFP4가 16개 원소 블록 + FP8(E4M3) 스케일을, MXFP4가 32개 원소 블록 + 거친 E8M0(2의 거듭제곱) 스케일을 쓰는 설계 차이에서 찾는다. 흥미로운 건, 블록을 작게 잘라 스케일을 세밀하게 주는 NVFP4 방식에서는 전통적인 이상치 완화 기법(Hadamard 회전 등)이 이론적으로 오히려 무력화된다는 걸 증명으로 보여준 점이다 — 블록이 작을수록 이상치가 블록 내에서 '희석'될 여지가 줄기 때문이다. 반대로 MXFP4는 거친 스케일 때문에 라운딩 오차가 크지만 회전 기반 기법과는 잘 맞는다. 저자들은 이 특성에 맞춰 블록 단위 Hadamard 회전과 포맷별 보정을 결합한 MR-GPTQ(Micro-Rotated-GPTQ)를 제안해 MXFP4의 정확도를 NVFP4와 1~2%p 차이로 좁혔다고 보고한다. 저비트 양자화 포맷을 고를 때 '몇 비트냐'보다 '블록 크기와 스케일 표현이 이상치 완화 기법과 어떻게 상호작용하느냐'가 실제 정확도를 가른다는 걸 보여주는 사례다."

  - title: "서브-1B 엣지 LLM을 위한 탐색 — LLMForge가 GPU 대신 '링 데이터플로우' 가속기까지 넣은 이유"
    type: "논문"
    summary: "하드웨어 인지 NAS(HW-NAS)는 주로 이미지 분류용 CNN이나 모바일 비전 모델을 겨냥해 발전해왔는데, 10억 파라미터 이하 엣지용 언어 모델에 그대로 적용하기엔 트랜스포머 특유의 어텐션/KV캐시 연산 패턴과 디코딩 단계의 메모리 바운드 특성이 다르다. LLMForge는 트랜스포머 전용 탐색 공간 Forge-Former와 NSGA-II 기반 다목적 탐색 엔진 Forge-DSE를 결합해 이 문제를 겨냥하는데, 특히 탐색 대상 하드웨어를 GPU·시스톨릭 어레이 가속기뿐 아니라 '링(ring) 데이터플로우' 구조의 엣지 가속기까지 포함한 멀티 백엔드 비용 모델로 넓힌 점이 특징이다 — 같은 아키텍처라도 어떤 가속기에 배치하느냐에 따라 최적 설계가 달라진다는 전제다. 링 데이터플로우 가속기 기준으로 탐색된 레이턴시 최적화 변형은 베이스라인 대비 TTFT(첫 토큰까지 지연)와 토큰당 지연을 43%, 토큰당 에너지를 40% 줄였다고 보고한다. 양자화나 가지치기가 '이미 정해진 아키텍처를 압축'하는 접근이라면, 이 연구는 '어떤 아키텍처를 쓸지 자체를 하드웨어에 맞춰 같이 찾는다'는 점에서 이 코너에서 다뤄온 경량화 기법들과는 다른 축의 레버를 보여준다."

  - title: "모든 양자화 기법이 다 다르게 무너진다 — '3.5 유효 비트'가 LLM PTQ의 보이지 않는 경계선"
    type: "논문"
    summary: "0.5B~14B 파라미터 LLM에 7가지 사후학습 양자화(PTQ) 기법을 체계적으로 적용해 비교한 이 연구는, '더 큰 모델을 세게 양자화하는 것'과 '더 작은 모델을 고정밀로 쓰는 것' 사이의 선택을 수치로 정리한다. 핵심 발견은 가중치당 '유효 비트수'(effective bits per weight — 단순 비트폭이 아니라 실제 보존된 정보량 기준)가 약 3.5비트를 넘는 지점부터는 세게 양자화된 큰 모델이 더 작은 고정밀 모델보다 성능이 앞서기 시작한다는 것이다. 이 경계선 아래로 내려가면 양자화 기법별로 정확도가 떨어지는 양상이 서로 다르게 갈라지고, 메모리·전력 소비도 같은 비트수에서도 알고리즘마다 차이가 크게 난다고 보고한다. 저자들은 이를 바탕으로 자원이 제한된 엣지 환경에서 '몇 비트로 양자화할까'보다 '이 비트수에서 어떤 PTQ 알고리즘을 쓸까'를 먼저 따져야 한다는 실무 가이드라인을 제시한다. 개별 PTQ 기법 논문들을 가로질러 '효율적 정밀도의 경계가 어디인가'라는 공통된 질문에 답을 시도한 연구라서, 다른 양자화 기법 비교를 읽을 때 기준점으로 삼기 좋다."
    source_url: "https://arxiv.org/abs/2505.15030"
