  - title: "VLA 자율주행 모델의 2년을 한 장의 지도로 — '엔드투엔드 vs 듀얼시스템'이라는 분류축"
    type: "논문"
    summary: "최근 2~3년 사이 자율주행 쪽에 쏟아진 VLA(Vision-Language-Action) 계열 연구는 저마다 다른 이름과 구조를 내세우고 있어서, 처음 이 분야를 공부하는 사람이 전체 지형을 파악하기가 쉽지 않다. Hu 등이 내놓은 이 서베이는 이 모델들을 크게 두 갈래로 나눈다. 하나는 하나의 모델이 인지부터 궤적 생성까지 한 번에 처리하는 '엔드투엔드 VLA'이고, 다른 하나는 느리게 돌아가는 고수준 언어·추론 모듈과 빠르게 돌아가는 저수준 제어 모듈을 분리해 둔 '듀얼시스템 VLA'다. 전자는 설계가 단순하고 end-to-end 최적화가 가능하지만 추론 지연이 안전 크리티컬한 제어 루프를 느리게 만들 위험이 있고, 후자는 System 1/System 2 인지과학 개념을 빌려와 추론과 제어의 주기를 분리함으로써 이 문제를 완화하려 한다는 식으로, 초기 Vision-Action 모델에서 현재의 VLA 프레임워크로 이어지는 흐름을 하나의 축으로 정리해 보여준다. 개별 논문을 따라가기 전에 이 분야가 어떤 설계 문제(추론과 제어의 속도 불일치)를 풀려고 분화해왔는지 먼저 이해하고 싶은 사람에게 좋은 출발점이 되는 자료다."
    source_url: "https://arxiv.org/abs/2512.16760"
  - title: "추론은 느리게, 운전은 빠르게 — AutoMoT가 '하나의 VLA' 안에 두 개의 속도를 넣은 방법"
    type: "논문"
    summary: "VLA 모델을 자율주행에 쓸 때 흔히 부딪히는 문제는, 사전학습된 비전-언어 모델의 추론 능력을 그대로 살리려 하면 추론 공간과 실제 조향·가속 같은 행동 공간 사이에 분포 불일치가 생기거나, 반대로 행동에 맞춰 모델을 세게 미세조정하면 원래 VLM이 가진 범용 추론 능력이 손상된다는 점이다. ICML 2026에 채택된 AutoMoT는 이 둘을 분리하지 않고 하나의 모델 안에서, 공유된 조인트 어텐션 위에 믹스처-오브-트랜스포머 구조를 올려 고수준 장면 추론과 저수준 주행 행동 생성이 서로 다른 주기로 '비동기적으로' 돌아가게 만드는 방식을 택했다. 여기에 디퓨전 기반으로 미세조정되는 액션 리파이너를 더해 생성된 행동을 다시 다듬는데, 이 설계는 결국 '추론을 늦추지 않으면서 제어를 늦추지도 않는' fast-slow 추론을 하나의 네트워크 안에서 구현하려는 시도로, 앞서 언급한 엔드투엔드 VLA의 지연시간 문제에 대한 구체적인 해법 중 하나를 보여준다."
    source_url: "https://arxiv.org/abs/2603.14851"
