    type: "논문"
    summary: "대부분의 궤적 예측 모델은 순수 데이터 기반 어텐션·그래프 신경망으로 에이전트 간 상호작용을 학습하는데, 구조적 사전지식(prior) 없이 데이터 분포에만 의존하다 보니 학습 분포를 벗어난 장면에서 일반화가 잘 되지 않는다는 한계가 꾸준히 지적되어 왔다.
