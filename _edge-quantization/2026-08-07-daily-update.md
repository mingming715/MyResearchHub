  - title: "아날로그 Compute-in-Memory의 하드웨어 노이즈를 반영한 비균일 혼합정밀도 양자화(NANQ)"
    type: "논문"
    summary: "아날로그 CIM(compute-in-memory) 칩은 저전력 온디바이스 추론에 유리하지만, 소자 편차와 읽기 노이즈가 저비트 양자화 모델의 정확도를 크게 떨어뜨린다는 문제가 있다. 기존 CIM 지향 양자화 기법들은 이상적인 양자화 오차만 최소화할 뿐 실제 하드웨어의 노이즈 바닥(noise floor)을 무시해 비트를 비효율적으로 배분해 왔다는 것이 저자들의 지적이다. NANQ는 실제 eFlash CIM 어레이에서 측정한 크기 의존적 가중치 노이즈 프로파일을 모델링해, 노이즈가 적은 영역에는 더 세밀한 양자화 해상도를 주고 노이즈가 지배적인 영역에는 불필요한 정밀도를 배정하지 않는 적응형 양자화 밀도를 설계하며, 레이어별로 하드웨어 노이즈 하에서 정확도 개선이 멈추는 '정밀도 포화점'을 찾아 자동으로 비트폭을 결정한다. 이는 아날로그 인메모리 연산이라는 비-디지털 하드웨어 환경에서 정확도-에너지 효율 트레이드오프를 노이즈 인지 관점으로 재구성한 사례다."
    source_url: "https://arxiv.org/abs/2608.02700"
  - title: "Recurrent Residual Quantization: 하나의 체크포인트에서 여러 정밀도를 뽑아내는 점진적 잔차 양자화"
    type: "논문"
    summary: "엣지 배포 환경마다 메모리·처리량 제약이 달라 다양한 비트폭의 모델이 필요하지만, 기존 PTQ 방식은 목표 비트폭마다 별도의 체크포인트를 새로 만들어야 해 저장 비용과 준비 시간이 크다는 문제가 있다. RRQ(Recurrent Residual Quantization)는 2비트로 양자화한 베이스 가중치 위에 2비트 잔차 보정을 반복적으로 쌓아 4·6·8비트 표현을 하나의 체크포인트에서 파생시키는 PTQ 프레임워크로, 캘리브레이션이나 여러 비트를 동시에 최적화하는 과정 없이 RTN(round-to-nearest)만으로 잔차를 생성한다. Qwen3-8B 실험에서 2/4/6/8비트 전체 패키지를 GPTQ 대비 3.3배 빠른 약 1,293초 만에 구성할 수 있음을 보여, 여러 정밀도를 동시에 서빙해야 하는 온디바이스 배포 상황에서 준비 비용과 유연성 사이의 트레이드오프를 개선한다."
    source_url: "https://arxiv.org/abs/2608.04048"
  - title: "MXSens: 마이크로스케일링 포맷과 결합한 컬럼·레이어 민감도 기반 혼합정밀도 양자화"
    type: "논문"
    summary: "4비트 양자화는 LLM 추론을 효율화하지만 활성값 이상치(outlier) 때문에 정확도가 크게 떨어지며, 기존 회전 기반이나 혼합정밀도 정수 양자화는 소프트웨어 스케일 관리와 잦은 역양자화로 오버헤드가 크고 스케일을 하드웨어에 직접 인코딩하는 MXINT 같은 마이크로스케일링 포맷과는 호환되지 않는다는 한계가 있다. MXSens는 이상치가 극단적으로 드문 경우부터 흔하지만 약한 편차까지 다양하게 분포하고 양자화 민감도가 레이어와 컬럼마다 고르지 않다는 분석에 기반해, 별도 학습 없이 컬럼·레이어별 민감도에 따라 4/6/8비트 가수부(mantissa) 비트폭을 배분하는 방법을 제안한다. W4A4KV4 설정에서 LLaMA-2-70B와 LLaMA-3-8B에 각각 3.77, 7.63의 perplexity를 달성해 기존 기법 대비 크게 개선함으로써, 하드웨어 친화적 마이크로스케일링 포맷 안에서도 이상치에 강건한 저비트 양자화가 가능함을 보인다."
    source_url: "https://arxiv.org/abs/2607.17733"
