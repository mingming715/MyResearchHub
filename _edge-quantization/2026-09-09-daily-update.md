    type: "논문"
    summary: "엣지 AI용 언어모델 선택이 흔히 정확도, 지연시간, 메모리, 에너지, 안전성 중 단 하나의 지표만 보고 이뤄지지만 실제 배포 가능한 모델은 이 다섯 가지를 동시에 만족해야 한다는 문제의식에서 출발해, 처음부터 작게 학습된 소형 언어모델(SLM)과 큰 LLM을 사후 양자화(PTQ)로 압축한 모델 중 어느 쪽이 더 지속가능한 엣지 배포 트레이드오프를 제공하는지를 정면으로 비교한 연구다. BF16 SLM 5종과 BF16·INT8·NF4 4비트·GPTQ 4비트·GGUF Q4 등 다양한 양자화를 적용한 LLM 5종을 조합해 총 30개 구성을 실측하고, 경제(역량·시스템 효율성)·환경(GPU 연산 에너지)·사회(유해 프롬프트에 대한 견고성)라는 세 축을 하나로 합친 재현 가능한 '전체론적 지속가능성 점수(HSS)'를 제안한다. 이 연구가 의미 있는 이유는 '양자화하면 작아지고 빨라진다'는 단순한 통념을 넘어, 네이티브 소형 모델과 압축된 대형 모델이 정확도만이 아니라 에너지 소비와 공격 견고성 측면에서도 서로 다른 트레이드오프 곡선을 그린다는 것을 정량적으로 드러내, 엣지 배포 시 '어떤 모델을 양자화할지'가 아니라 '애초에 작게 학습할지 크게 만들어 압축할지'라는 상위 설계 질문에 데이터를 제공한다는 점이다."

  - title: "Prune-Quantize-Distill — 압축 기법을 어떤 순서로 쌓아야 실제 CPU 지연시간이 줄어드는가"
    type: "논문"
    summary: "가지치기(pruning), INT8 양자화 인식 학습(QAT), 지식 증류(KD)를 결합해 쓰는 것 자체는 널리 알려져 있지만 이 논문은 세 기법을 '어떤 순서로' 적용하느냐가 결과에 결정적이라는 점을 통제된 순서 뒤섞기(ablation) 실험으로 보인다. 20/40/40 에폭 배분을 고정한 채 순서만 바꿔가며 비교한 결과 가지치기 → INT8 QAT → KD 순서가 가장 강한 정확도-크기-지연시간 프론티어를 만들어냈으며 0.99~1.42ms의 CPU 지연시간을 달성했는데, 그 메커니즘을 보면 INT8 QAT가 런타임 이득의 대부분을 차지하는 반면 가지치기는 이후 저정밀 최적화의 강건성을 높이는 '용량 축소 전처리'로만 기능하고, KD는 마지막 단계에서 이미 제약된 희소·저정밀 상태의 정확도를 형태를 바꾸지 않고 회복시키는 역할을 한다는 것이다. 특히 흥미로운 지점은 비구조적 가지치기가 모델 저장 용량은 줄이면서도 불규칙한 메모리 접근과 희소 커널 오버헤드 때문에 표준 CPU 실행에서는 오히려 속도를 늦출 수 있다는 사실로, 파라미터 수나 FLOPs 같은 압축 대리 지표가 실제 벽시계 추론 시간을 신뢰성 있게 예측하지 못한다는 것을 실측으로 보여준다. '압축 기법을 비교'하는 것을 넘어 '같은 기법들을 어떤 순서로 조합해야 하는가'라는, 실무에서 자주 간과되는 질문에 구체적 근거를 제시한다."
    source_url: "https://arxiv.org/abs/2604.04988"
  - title: "Point4Bit — 복셀 기반 3D 검출기를 INT4까지 내리는 첫 범용 사후 양자화 프레임워크"
    type: "논문"
    summary: "기존 포인트클라우드 3D 검출용 PTQ 기법들은 대체로 INT8 수준에 머물러 있었는데, 그 이유는 포인트클라우드가 희소하고 전경(foreground) 포인트가 소수인 불균일한 구조를 가지기 때문에 활성화값을 더 낮은 비트로 내리면 검출에 결정적인 전경 특징이 쉽게 손상되기 때문이다. Point4Bit는 이 문제를 두 가지 기법으로 공략하는데, 전경 구조 단서를 활용해 희소 활성화를 구간별로 다르게 양자화하는 Foreground-aware Piecewise Activation Quantization(FA-PAQ)과, 그래디언트 기반 분석으로 태스크에 결정적인 가중치를 식별해 우선 보존하는 Gradient-guided Key Weight Quantization(G-KWQ)을 결합해 INT4 설정에서도 정확도 저하를 1.5%p 미만으로 억제했으며 포인트클라우드 분류·분할 태스크로도 일반화가 확인됐다. 지금까지 LiDAR/포인트클라우드 영역의 양자화 연구가 대체로 INT8 안에서의 아키텍처별 열화 차이를 다뤄온 것과 달리, 이 논문은 비트폭 자체를 INT4까지 밀어붙이면서도 정확도를 지킬 수 있음을 보여, 비-이미지 도메인에서 저비트 양자화의 한계가 어디까지 밀릴 수 있는지를 갱신한 사례다."

  - title: "TARQ — 평균 WER은 그대로인데 희귀 단어 인식률만 조용히 무너지는 ASR 양자화의 숨은 위험"
    type: "논문"
    summary: "음성인식(ASR) 모델을 데이터 기반 PTQ로 압축할 때 표준 보정(calibration) 절차는 말뭉치에 흔한 단어들 위주로 이뤄지기 때문에 인명·숫자·도메인 전문용어 같은 '꼬리(tail)' 어휘는 보정 과정에서 상대적으로 적은 비중만 반영되고, 그 결과 전체 평균 단어 오류율(WER)은 거의 변하지 않아 보여도 실제로는 드물지만 중요한 단어에서 오류가 집중적으로 증가하는 현상이 발생한다는 것이 이 논문의 출발점이다. TARQ는 엔티티 라벨도, 별도로 큐레이션한 보정 데이터셋도, 추가 학습도 없이 각 Linear 레이어마다 흔한 단어와 꼬리 단어의 보정 비중을 균형 맞추는 닫힌 형태의 규칙(rareBAL)과 지표에 부합하는 잔차 보정을 결합한 라벨-프리 PTQ 기법으로, Whisper tiny부터 large, Qwen3-ASR, Voxtral-Mini까지 8개 ASR 백본과 6개 데이터셋에 대해 W4G128(4비트 가중치, 그룹크기 128) 설정에서 전체 WER을 희생하지 않으면서 희귀 단어 WER을 개선하고 말뭉치 간 희귀 단어 오류 변동폭도 가장 낮게 억제했다. 이는 앞서 반복적으로 확인돼 온 '양자화 손상이 소수 레이어에 집중되지 않고 전 레이어에 퍼져 있다'는 관찰을 어휘 빈도 축으로 확장한 것으로, 정확도 평균값만 보고 양자화된 모델의 배포 가능성을 판단하는 관행이 실제 사용자에게 중요한 실패를 가릴 수 있음을 경고한다."
