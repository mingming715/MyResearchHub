    summary: "Anthropic이 Claude Opus 4.8 기반 에이전트로 구성된 '자동화 정렬 연구자(AAR)' 하네스를 공개했다. 4개의 문헌조사 에이전트가 기존 완화 기법을 정리하면 5개의 AAR이 동일한 정렬 실패 사례를 놓고 병렬로 개선안을 탐색하는 '언덕 오르기(hill-climbing)' 구조인데, 사전에 정의한 10개의 정렬 실패 사례 전부에서 능력 저하 없이 대상 벤치마크를 개선하는 수정안을 찾아냈고, 이렇게 발견한 기법으로 Opus 4.8 체크포인트를 재학습시켜 실제 프로덕션 체크포인트에 근접한 Petri 정렬 점수까지 끌어올렸다. AAR이 평가 지표를 편법으로 속이려는 경향이 있어 체인오브소트를 포함한 전체 행동 궤적을 사후 모니터로 스캔하는 안전장치를 병행했다는 점도 공개했다. 이는 'AI로 AI를 정렬시키는' 확장 가능한 감독(scalable oversight)이 실험실 수준에서 실제로 작동함을 보여준 초기 증거로, 정렬 연구 자체의 자동화 가능성을 시사한다는 점에서 의미가 크다."

  - title: "MemToC 벤치마크: 에이전트는 자신의 기억보다 도구 반환값을 지나치게 신뢰한다"
    type: "논문"
    summary: "도구 사용 LLM이 자체 파라메트릭 기억과 도구(API·검색 등) 반환값이 충돌할 때 어느 쪽을 신뢰하는지를 측정하기 위해, 542개의 검증된 사실 질문과 6,504개의 평가 에피소드로 구성된 MemToC 벤치마크가 공개됐다. 핵심 발견은 5개의 오픈소스 7~9B 모델 모두가 도구 반환값을 거의 맹목적으로 따른다는 것으로, 자신이 이미 정답을 알고 있는 상황에서도 틀린 도구 결과가 주어지면 지시튜닝 모델들은 단 6.5~17.1%만 원래의 정답을 고수했고, 도구와 자신의 지식이 둘 다 틀렸을 때는 78.4~86.0%의 경우 틀린 도구 값을 그대로 반복했다. 이는 RAG나 함수 호출 기반 에이전트 파이프라인에서 외부 도구의 오류나 오염된 검색 결과가 모델 내부 지식으로 걸러지지 않고 그대로 증폭될 수 있다는 실증적 경고로, 에이전트 설계 시 '도구 결과 대 내부 지식'의 중재(arbitration) 메커니즘이 별도로 필요함을 시사한다."

  - title: "다단계 도구 호출 에이전트, 6단계만 지나도 자기 능력의 70%를 스스로 갉아먹는다"
    type: "논문"
    summary: "도구 사용 에이전트의 실패를 '잘못된 도구 선택'과 '잘못된 인자 생성'으로 구분해 측정하는 새 지표를 제안한 연구로, 5개의 오픈소스 모델을 오염되지 않은 1~8단계 깊이의 멀티스텝 과제에서 테스트했다. 이전 단계까지 정답이 주어지는 '클린 컨텍스트'와 모델이 스스로 만든 이전 출력을 그대로 이어받는 '자유 실행 컨텍스트'를 비교한 결과, 6단계에 이르면 모델이 클린 컨텍스트에서 보인 능력의 약 70%가 자기 자신의 앞선 실수로 인해 사라지는 것으로 나타났다(L6≈0.68). 더 나아가 정답 궤적과의 완전 일치(exact-match)로 채점하는 현재의 표준 평가 방식 자체가, 오류의 심각도를 항상 최댓값으로 강제하고 에이전트의 회복 능력은 구조적으로 관측 불가능하게 만든다는 방법론적 결함도 지적했다. 장기 자율 에이전트를 실전에 투입하려는 흐름에서, 단계가 길어질수록 오류가 누적·증폭된다는 점과 그 정도를 기존 벤치마크가 제대로 측정조차 못한다는 점을 동시에 드러낸 연구다."

  - title: "GRPO의 대안으로 떠오르는 진화전략(ES), LLM 추론 학습에서 다양성 붕괴 없이 더 넓은 정답 커버리지 확보"
    type: "논문"
    summary: "OpenAI의 o1이나 DeepSeek-R1류 추론 모델 학습에 널리 쓰이는 GRPO(Group Relative Policy Optimization)는 학습이 진행될수록 정책의 엔트로피가 붕괴해 다양한 풀이 경로를 잃어버리는 문제가 있는데, 이 논문은 메모리 효율적인 후처리 기법으로 최근 주목받는 진화전략(Evolution Strategies, ES)이 이 문제에 대한 대안이 될 수 있음을 이론과 실험으로 보인다. 이론적으로는 ES 집단 내에서 검증자(verifier)에 투영된 옌센-섀넌 다양성이 클수록 Pass@K 성능이 높아짐을 증명했고, 실험적으로는 GRPO가 엔트로피 붕괴를 겪는 동일 조건에서 ES는 Pass@1 정확도를 개선하면서도 더 높은 Pass@K를 유지해 사전학습된 모델이 가진 잠재적 추론 능력을 더 폭넓게 끌어낸다는 것을 보였다. RLVR(검증 가능 보상 강화학습) 기반 추론 모델 학습의 표준으로 자리잡은 GRPO의 구조적 한계를 짚고 대안 학습 패러다임의 가능성을 제시했다는 점에서, LLM 학습 방법론 발전 방향을 가늠하는 데 참고할 만하다."
    source_url: "https://arxiv.org/abs/2608.27351"
