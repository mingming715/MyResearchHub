    type: "논문"
    summary: "Edge TPU는 온칩 메모리가 작아서 모델이 조금만 커져도 런타임이 모델 조각을 호스트-가속기 메모리 사이로 스와핑해야 하는데, 이전 코너에서 다룬 LeanStream이 LLM 추론의 플래시 I/O 병목을 '추측-정제' 스트리밍으로 풀었던 것과 달리, 이 연구는 '어디까지를 CPU에 맡기고 어디부터를 TPU에 맡길지'를 잘못 정하면 스와핑이 줄기는커녕 레이턴시가 더 나빠질 수 있다는 걸 짚는다. SwapLess는 파티션 지점에 따라 달라지는 서비스 시간과 모델 간·모델 내 스와핑 오버헤드를 함께 반영하는 해석적 큐잉 모델을 세우고, 그 모델을 기준으로 파티션 지점과 CPU 코어 할당을 온라인으로 조정하는 그리디 힐클라이밍 탐색을 적용한다. 기본 Edge TPU 컴파일러 대비 단일 테넌트 워크로드에서 평균 레이턴시를 최대 63.8%, 여러 모델이 동시에 자원을 다투는 멀티 테넌트 환경에서는 최대 77.4%까지 줄였다고 보고한다. 양자화·가지치기가 '모델을 작게 만드는' 레버라면, 이 연구는 '이미 작아진 모델을 어떻게 쪼개 배치할지'를 최적화하는 또 다른 축의 레버라서, 온디바이스 추론을 레이턴시-메모리 트레이드오프로 이해하려는 사람에게 참고할 만하다."

  - title: "이상치를 지우는 대신 '헤시안의 사각지대'에 숨긴다 — OSAQ가 추가 연산 없이 2비트 양자화 오차를 줄인 방법"
    type: "논문"
    summary: "저비트(2~3비트) LLM 양자화에서 정확도를 갉아먹는 가장 큰 원인은 가중치·활성값의 이상치(outlier)인데, 기존 해법들은 대개 회전 변환이나 별도의 보정 단계를 추가해 이상치를 억제하면서 추론 비용이나 전처리 시간을 더 치르는 경우가 많았다. ICML 2026에 채택된 OSAQ(Outlier Self-Absorption)는 헤시안의 곡률이 거의 0에 가까운 '널 스페이스' 방향—즉 가중치를 그만큼 바꿔도 손실에 거의 영향을 주지 않는 방향—을 찾아, 그 방향으로 가중치에 덧셈 변화를 가해 이상치를 흡수시킨다. 이 보정값은 닫힌 형태로 계산되어 반복 최적화나 추가 학습이 필요 없고, 변화 자체가 가중치에 완전히 흡수되기 때문에 추론 시점에 별도 연산이 붙지 않는다는 게 핵심이다. GPTQ에 이 기법을 얹으면 2비트 양자화에서 vanilla GPTQ 대비 퍼플렉시티를 40% 이상 낮췄고, KV 캐시·활성값 양자화에도 플러그인 형태로 호환된다고 보고한다. 최근 이 코너에서 다룬 NVFP4·MXFP4 비교가 '어떤 포맷을 쓰느냐'의 문제였다면, 이 연구는 포맷과 무관하게 '이상치를 어디에 숨길 수 있는가'라는 보정 기법 자체의 다음 단계를 보여준다."
    source_url: "https://arxiv.org/abs/2605.04738"
