  - title: "GraphBEV++ - 완벽한 센서 정렬을 가정하지 않는 실전형 BEV 퓨전"
    type: "논문"
    summary: "BEVFusion류의 카메라-라이다 융합은 두 센서 데이터가 BEV 공간에 정확히 정렬돼 있다는 전제를 깔지만, 실제 양산차에서는 캘리브레이션 오차와 진동으로 인한 국소·전역 오정렬이 흔하다. GraphBEV++는 이 문제를 정면으로 다뤄, 그래프 매칭 기반으로 이웃 뎁스 정보를 활용해 국소 오정렬을 보정하는 LocalAlign-v2와, LSS 기반(BEVFusion류)에는 변형가능 어텐션으로 전역 오프셋을 직접 학습하고 쿼리 기반(BEVFormer류)에는 노이즈 주입 후 디노이징으로 정렬을 복원하는 GlobalAlign-v2를 제안한다. 두 가지 서로 다른 BEV 패러다임에 공통 적용 가능하도록 설계돼 occupancy 예측까지 일반화된다는 점에서, '완벽한 센서 정렬'이라는 비현실적 전제를 깨는 실용적 설계 사례다."
    source_url: "https://arxiv.org/abs/2606.16354"
  - title: "인식 모델을 업데이트하면 플래너가 망가진다 - End-to-End 자율주행의 숨은 유지보수 비용"
    type: "논문"
    summary: "End-to-end 자율주행은 인식과 판단을 하나의 latent 표현으로 강하게 결합시키는데, 이 논문은 '인식 모듈만 더 나은 백본이나 새 센서로 교체하면 latent representation이 바뀌면서 뒤에 고정된 planner가 제대로 작동하지 않게 된다'는, 실무에서는 흔하지만 논문화되지 않았던 문제를 정식화한다. 해법으로 제시한 'model stitching'은 전체 파이프라인을 재학습하는 대신 가벼운 어댑터만으로 새 인식 표현을 옛 정책이 이해하던 표현 공간에 재매핑하는 방식으로, 도메인 전환 실험에서 재적응 시간을 22.18시간에서 0.91시간으로 줄이면서도 주행 성능의 91% 이상을 유지했다. 'End-to-end가 모듈형보다 항상 우월하다'는 단순한 구도에 반례를 제시하며, 양산 단계에서 겪는 버전관리 비용이라는 설계 철학적 트레이드오프를 짚었다."
    source_url: "https://arxiv.org/abs/2606.21509"
  - title: "빠른 직관과 느린 숙고를 분리한 이중 프로세스 자율주행 플래너"
    type: "논문"
    summary: "VLM 기반 체계적 추론(Chain-of-Thought)은 판단 근거를 설명 가능하게 만들지만, 모든 주행 순간에 무거운 추론을 돌리는 것은 비효율적이고 지연시간 문제를 일으킨다. 이 논문은 인지과학의 이중과정이론(시스템1=빠른 직관, 시스템2=느린 숙고)을 자율주행 플래닝에 적용해, 가벼운 Arbiter가 장면 복잡도를 먼저 판단한 뒤 단순한 상황은 빠른 meta-action 예측으로, 복잡한 상황만 구조화된 chain-of-thought 추론으로 라우팅하는 구조를 제안한다. 사람이 일일이 라벨링하지 않고 인식 파운데이션 모델과 전문가 VLM을 조합해 추론 학습 데이터를 자동 생성하는 파이프라인도 함께 제시했다. '항상 최대 추론 능력을 쓰는 것'이 아니라 '상황에 따라 추론 비용을 동적으로 배분한다'는 설계 철학이 핵심이며, 플래닝 모듈 내부의 자원 배분이라는 구체적 엔지니어링 문제에 초점을 맞춘 점이 차별점이다."
    source_url: "https://arxiv.org/abs/2607.19194"
  - title: "Sparse4D-Radar - 차량 탑재 실시간성을 겨냥한 4D 레이더-카메라 서라운드뷰 융합"
    type: "논문"
    summary: "기존 BEVFusion, RCFusion 같은 dense 융합 기법은 LSS(Lift-Splat-Shoot) 방식의 메모리 집약적 연산 때문에 1,800~2,900 GFLOPs에 달해 차량용 컴퓨트에서 실시간 처리가 어려운데, Sparse4D-Radar는 sparse query 기반 구조로 이를 우회해 약 470~480 GFLOPs 수준(4~6배 절감)으로 낮추면서도 단일 RTX 4090 기준 11.5 FPS(경쟁 기법 대비 3배 이상)를 달성했다. 4D 레이더와 카메라를 융합할 때 '정확도'뿐 아니라 '실제 차량 SoC에 올릴 수 있는 연산량'이 핵심 제약이라는 점을 잘 보여주는 사례로, 라이다-카메라 중심으로 다뤄지던 센서 퓨전 알고리즘 논의를 저비용 4D 레이더 쪽으로 넓혀준다."
    source_url: "https://arxiv.org/abs/2607.04098"
