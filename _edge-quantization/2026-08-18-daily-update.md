  - title: "생각의 흔적까지 캘리브레이션에 담는다 — 추론 LLM용 1.58비트 PTQ, ScaleQ-1.58"
    type: "논문"
    summary: "삼진(ternary, 1.58비트) 양자화는 LLM의 메모리와 추론 속도를 크게 줄일 수 있지만, 사고 과정을 거치는 추론 특화 LLM에 사후양자화(PTQ)를 적용하면 수학·코딩 같은 어려운 과제에서 성능이 급격히 붕괴해 실배포가 드물었다. 이 논문은 기존 PTQ 캘리브레이션이 모델의 연쇄적 사고(chain-of-thought) 과정을 무시한 채 짧은 프롬프트-응답 쌍만으로 보정 데이터를 구성하는 것을 문제의 근원으로 지목하고, 원본 고정밀도 모델이 스스로 생성한 추론 궤적과 최종 답변을 보정 샘플로 삼는 AYOT(Attend to Your Own Thoughts) 캘리브레이션 기법을 제안한다. 이를 담은 ScaleQ-1.58 프레임워크는 양자화된 모델이 실제 다단계 추론 과정에서 마주치는 활성값 분포에 맞춰 스케일을 잡도록 만들어, 기존 캘리브레이션 대비 어려운 추론 벤치마크에서의 붕괴를 완화한다. 이는 저비트 양자화 정확도가 비트폭 자체보다 캘리브레이션 데이터를 무엇으로 어떻게 구성하느냐에 좌우된다는 최근 흐름에, 모델이 어떻게 생각하는지를 반영해야 한다는 새로운 축을 더한 결과다. 다만 추론 궤적 생성 자체가 원본 모델의 추가 추론을 요구하므로, 캘리브레이션 비용은 기존 방식보다 늘어난다는 점은 실무 적용 시 감안해야 한다."
    source_url: "https://arxiv.org/abs/2608.01078"
  - title: "느슨한 설정값을 찾아 전력을 아낀다 — 온디바이스 LLM 추론의 에너지 인식 스케줄러 EnerInfer"
    type: "논문"
    summary: "온디바이스 LLM 추론은 프라이버시와 비용 면에서 매력적이지만 배터리 구동 기기에서는 에너지 소모와 발열이 실질적 병목이며, 기존 최적화는 모델마다 일일이 프로파일링해 최적 설정을 찾아야 했다. EnerInfer는 온디바이스 추론에 설정 여유(configuration slack)가 존재한다는 관찰에서 출발한다. 즉 NPU와 메모리 클럭을 약간 낮춰도 사용자 체감 품질(QoE)은 유지되면서 에너지 효율은 크게 개선될 수 있다는 것이다. 매 모델을 새로 프로파일링하는 대신 모델의 구조적 특징으로부터 처리량과 전력을 예측하는 블랙박스 예측 모델을 학습시켜, 약 300개 생성 모델에 대한 5분 내외의 데이터 수집만으로 새 플랫폼에 하루 안에 맞춤 튜닝을 가능하게 하고, 런타임 열 예측기로 발열 상황에 따라 열 인식 제어를 동적으로 켜고 끈다. 이는 양자화나 프루닝처럼 모델 자체를 바꾸지 않고도 하드웨어 설정 탐색만으로 온디바이스 추론의 에너지 효율을 크게 끌어올릴 수 있음을 스마트폰·노트북·개발보드 등 이종 플랫폼에서 보여준 사례로, 모델 경량화 기법과 상호보완적으로 결합될 여지를 시사한다. 다만 예측 모델 자체가 플랫폼별 사전 데이터 수집에 의존하므로, 완전히 새로운 하드웨어 세대에 대한 일반화는 추가 검증이 필요한 한계로 남는다."
    source_url: "https://arxiv.org/abs/2606.23001"
  - title: "레이어·헤드·MLP를 한 번에 — LLM 프루닝의 지연시간-크기 다목적 파레토 탐색"
    type: "논문"
    summary: "LLM을 임베디드·엣지 환경에 배포하려면 지연시간·메모리·에너지 제약을 동시에 만족해야 하는데, 레이어 수·어텐션 헤드·MLP 차원을 함께 줄이는 구조적 프루닝은 설계 공간이 방대해 전수 탐색이 사실상 불가능하고 국소 최적해나 불안정한 구성에 빠지기 쉽다는 문제가 있었다. 이 논문은 레이어, 어텐션 헤드, MLP 차원을 동시에 조정 대상으로 삼는 하드웨어 인식 다목적 구조적 프루닝 프레임워크를 제안해, 정확도를 유지하면서 지연시간과 모델 크기라는 두 목적함수에 대해 파레토 최적에 가까운 여러 프루닝 구성을 한 번의 탐색으로 얻어낸다. 서버급 GPU와 엣지 플랫폼 양쪽에서 평가해, 다운스트림 성능 저하를 억제하면서도 종단간 추론 지연시간을 줄이는 구성들을 확인했다. 파라미터 수 최소화 같은 단일 목표로 프루닝하던 기존 접근과 달리 배포 환경마다 다른 지연시간-크기 요구에 맞춰 하나의 파레토 프론트에서 골라 쓸 수 있다는 점에서 실무적 유연성이 크며, 최근의 그룹별 강건성 프루닝 함정 연구와 함께 무엇을 어떻게 잘라내느냐의 설계가 정확도-효율 트레이드오프의 핵심이라는 흐름을 뒷받침한다. 다만 다목적 탐색 자체가 여러 후보 구성을 학습·평가해야 하므로, 단일 목표 프루닝보다 탐색 비용이 늘어나는 트레이드오프는 피할 수 없다."
    source_url: "https://arxiv.org/abs/2607.22583"
