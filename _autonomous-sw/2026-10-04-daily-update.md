    type: "뉴스"
    summary: "국내 모빌리티 업계에서도 자율주행 소프트웨어 아키텍처 논쟁이 추상적 담론을 넘어 실제 제품 설계 선택으로 넘어오고 있다. 카카오모빌리티는 연내 기존 규칙 기반 AI 플래너를 확장해, 센서 입력을 하나의 신경망이 통합 처리해 주행 궤적까지 출력하는 E2E 모델을 서울자율차에 도입하기로 했는데, 핵심은 'E2E의 판단을 그대로 차량 제어에 넘기지 않는다'는 설계다. E2E가 여러 주행 경로 후보를 예측하면, 교통법규와 차량의 물리적 한계를 규칙 기반으로 재확인하는 별도의 '세이프티 이밸류에이터'가 그 결과를 다시 검증한 뒤에야 제어로 넘긴다 — 예컨대 어린이보호구역에서는 E2E가 통과해도 된다고 판단해도 규칙 기반 안전 기준이 우선 적용되고, 복잡한 교차로에서는 무리한 끼어들기 대신 대기를 선택하도록 안전 평가기가 개입한다. 이는 'E2E냐 모듈형이냐'라는 이분법 대신, E2E의 유연성과 모듈형의 해석가능성·검증가능성을 한 스택 안에 공존시키는 하이브리드 설계가 실제 양산 단계에서 선택되고 있음을 보여주는 국내 사례다. 강남 지역 1.3만km 누적 주행 데이터를 바탕으로 연말 레벨4 상용화를 목표로 한다는 점도, 데이터 축적과 아키텍처 전환이 맞물려 진행되는 흐름을 보여준다."

  - title: "불확실성 지도를 VLM이 그린다 — CRUISE, 센서별 '어디를 믿을지'를 언어모델에게 묻다"
    type: "논문"
    summary: "카메라·라이다·레이더를 결합하는 기존 센서 퓨전은 각 센서의 신뢰도가 안개·블러·노출 변화 같은 실제 주행 조건에서 시시각각 달라진다는 점을 충분히 반영하지 못한 채, 거리 기반의 단순한 불확실성 추정치에 의존해왔다. CRUISE는 여기에 비전-언어모델(VLM)을 끼워 넣어 각 센서 입력의 어느 영역이 신뢰할 만한지를 맥락을 이해한 픽셀 단위 불확실성 히트맵으로 변환하고, 이 히트맵을 크로스모달 퓨전 가중치에 직접 반영한다. '거리가 멀면 불확실하다'는 식의 물리적 추정이 아니라 '안개 낀 이 영역의 카메라 픽셀은 지금 믿을 수 없다'는 장면 맥락 판단을 언어모델에게 맡긴다는 발상의 전환이 핵심이다. 안개·블러·노출 변화·센서 노이즈를 시뮬레이션한 세 개 데이터셋에서 기존 퓨전·불확실성 정량화 기법 대비 3D 객체 탐지 4.87%, 시맨틱 분할 4.23%의 평균 성능 향상을 보고했다. 불확실성 추정 자체를 저수준 통계가 아니라 고수준 의미 이해의 산물로 재정의하려는 시도로서, VLM을 인지 파이프라인의 '판단 보조 센서'처럼 쓰는 최근 흐름과 맞닿아 있다."
    source_url: "https://arxiv.org/abs/2608.09202"
  - title: "합성 데이터를 얼마나 섞을지, 사람이 정하지 말고 모델이 스스로 찾게 하라 — AutoScale의 폐루프 데이터 믹싱"
    type: "논문"
    summary: "실데이터와 합성 데이터를 함께 학습시키는 co-training은 보통 '전체의 몇 %를 합성 데이터로 채울지'를 고정된 비율로 미리 정해두는데, 이 비율이 씬 분포나 학습 단계에 따라 최적이 아닐 수 있다는 문제는 그간 충분히 다뤄지지 않았다. AutoScale은 데이터 비율 결정 자체를 '모델 성능을 최대화하는 동적 최적화 문제'로 재정의해, 그래프 정규화 오토인코더(Graph-RAE)로 주행 장면을 표현하고 클러스터 단위로 중요도를 추정해 가중치를 재조정하는 Cluster-GA, 그리고 클러스터 기반 벡터 검색으로 고가치 샘플만 뽑아오는 과정을 닫힌 루프(closed-loop) 평가 피드백으로 반복 조정하는 완전 자동화 데이터 엔진을 제안한다. '얼마나 많은 합성 데이터를 썼는가'가 아니라 '어떤 합성 데이터를 어느 시점에 얼마나 넣을지를 평가 신호로부터 계속 갱신한다'는 점에서, 최근 Dream4Drive 등이 보여준 '합성 데이터 설계' 트렌드를 데이터 배합 전략이라는 또 다른 축에서 보완한다. NavSim 벤치마크에서 제한된 예산 아래 더 적은 합성 샘플로도 기존 co-training·크로스도메인 기법들을 앞섰다는 결과는, 시뮬레이션 데이터 활용의 다음 병목이 '생성 품질'을 넘어 '배합 전략'으로 옮겨가고 있음을 보여준다."
    source_url: "https://arxiv.org/abs/2605.21372"
