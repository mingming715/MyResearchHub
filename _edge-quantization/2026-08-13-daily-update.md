    type: "논문"
    summary: "PTQ의 정확도는 결국 캘리브레이션 데이터가 실제 추론 시 활성화 분포를 얼마나 잘 대표하느냐에 달려 있는데, 소량의 일반 캘리브레이션 샘플만으로는 이 대표성이 부족하다는 게 고질적 병목이다. FAQ(Family-Aware Quantization)는 원본 캘리브레이션 샘플을 같은 모델 계열의 더 큰(상위) LLM에 통과시켜 지식 체계가 일관된 고품질 캘리브레이션 데이터를 재생성하는 방식으로 이 문제를 우회한다. Wikitext2·C4·LAMBADA 등에서 측정한 perplexity 기준으로 INT8·INT4 양쪽 PTQ 방법 대부분의 언어모델링 성능을 개선시켰다는 결과를 보였다. 모델 구조나 알고리즘을 건드리지 않고 \"캘리브레이션 데이터 자체의 질\"이라는, 상대적으로 덜 주목받은 지렛대를 다뤘다는 점이 특징이다."
