  - title: "EdgeLPR - 라이다 장소 인식(Place Recognition)에서 정밀도-성능 트레이드오프를 체계적으로 재본 벤치마크"
    type: "논문"
    summary: "라이다 기반 장소 인식(place recognition)은 SLAM·로봇 주행에서 루프 클로저를 판단하는 핵심 모듈이지만, 그동안 양자화 연구는 주로 3D 객체 검출에 집중돼 이 태스크의 정밀도-성능 트레이드오프는 상대적으로 덜 다뤄졌다. EdgeLPR은 포인트클라우드를 BEV(Bird's Eye View)로 변환해 경량 이미지 네트워크를 그대로 쓸 수 있게 한 뒤, 어그리게이션 헤드 없이 전역 풀링과 선형 투영만으로 디스크립터를 뽑는 통일된 구조로 여러 아키텍처를 FP32·FP16·INT8 세 정밀도에서 나란히 벤치마킹했다. 핵심 발견은 FP16은 FP32와 정확도가 거의 같으면서 비용만 줄어드는 반면, INT8은 아키텍처에 따라 성능 저하 폭이 크게 갈린다는 것으로, 하나의 고정된 양자화 레시피가 모든 구조에 통하지 않는다는 것을 실증했다. 3D 검출 중심으로 논의되던 라이다 양자화 이슈를 장소 인식이라는 다른 다운스트림 태스크로 확장하고, '태스크·아키텍처를 함께 고려한 양자화'가 필요하다는 근거를 제공한다는 점에서 비-이미지 도메인 양자화를 공부하는 데 참고할 만하다."
    source_url: "https://arxiv.org/abs/2605.02275"
  - title: "GRASPrune - FFN 채널과 KV 헤드를 하나의 전역 예산으로 동시에 가지치기하는 LLM 구조적 프루닝"
    type: "논문"
    summary: "LLM 서빙 비용은 파라미터 자체뿐 아니라 어텐션 연산과 KV 캐시에서도 크게 발생하는데, 기존 구조적 프루닝은 대부분 중요도 점수를 제약 없이 먼저 학습한 뒤 사후에 목표 압축률(budget)을 적용해 학습 목표와 실제 프루닝 결과 사이에 괴리가 생기는 문제가 있었다. GRASPrune은 FFN 채널과 KV 헤드 그룹을 하나의 전역 예산 아래 동시에 가지치기하는 프레임워크로, 프로젝션 기반 STE(straight-through estimator)를 이용해 학습 매 스텝마다 목표 예산을 정확히 만족하는 하드 마스크를 유지하면서 백본 가중치는 고정한 채 가벼운 게이트 점수만 학습하고, 마스크 확정 후에는 잔여 유닛의 스케일 불일치를 보정해 추가 파라미터 없이 그대로 작아진 조밀(dense) 체크포인트를 얻는다. LLaMA-2-7B에서 파라미터 50%를 제거하고도 WikiText-2 퍼플렉서티 12.18을 달성했으며, 단일 A100에서 레이블 없는 캘리브레이션 시퀀스 512개로 4에폭만 학습해 전체 파인튜닝 없이도 5개 제로샷 벤치마크에서 경쟁력 있는 정확도를 유지했다. 프루닝을 '중요도 계산 후 자르기'가 아니라 '예산 제약을 처음부터 학습에 내장하기'로 재정식화했다는 점에서, 양자화 일변도의 경량화 논의에 프루닝 쪽의 최신 설계 원리를 더해주는 사례다."
    source_url: "https://arxiv.org/abs/2604.19398"
  - title: "얼리 엑시트 네트워크의 하드웨어-알고리즘 공동 최적화 - 양자화 비트폭과 출구 배치, 가속기 매핑의 숨은 상호작용"
    type: "논문"
    summary: "얼리 엑시트 신경망(EENN)은 입력별로 조기에 추론을 종료해 평균 연산량을 줄이는 동적 추론 기법인데, 멀티코어 엣지 가속기에 배포할 때는 단순 MAC(곱셈-누산) 연산량만으로는 설명되지 않는 하드웨어 효율 문제가 발생한다. 이 논문은 출구(exit) 위치, 양자화 비트폭, 가속기로의 워크로드 매핑이 서로 독립적이지 않고 텐서 차원 정렬과 데이터플로우 방식에 따라 메모리 트래픽·가속기 활용률·에너지-지연 트레이드오프에 비선형적으로 영향을 준다는 것을 분석적 설계공간 탐색으로 규명하고, 이를 정확도·에너지-지연곱·출구 오버헤드·동적 추론 행동을 함께 고려하는 제약 다목적 최적화 문제로 정식화한다. CIFAR-10 실험에서 8비트 양자화 조건 하에 이 방식으로 찾은 아키텍처가 정적 베이스라인 대비 에너지-지연곱을 50% 이상 줄이는 결과를 보였다. 그동안 양자화 비트폭은 대체로 모델 구조와 독립적인 후처리 변수로 다뤄져 왔는데, 이 연구는 비트폭 선택이 동적 추론 구조(출구 배치)·가속기 매핑과 얽혀 있어 따로따로 최적화하면 손해를 본다는 것을 보여준다는 점에서, 레이턴시·전력을 다루는 온디바이스 추론 최적화 논의에 새로운 축을 더한다."
    source_url: "https://arxiv.org/abs/2512.04705"
